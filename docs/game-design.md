# 命の砂時計のゲーム企画

3Dの小さな町で暮らす人々を見守り、出会いや時間の使い方に少し働きかける人生シミュレーション。住人への愛着、自分で考えた働きかけ、その先に生まれる予想外の暮らしを楽しむ。

初期の舞台は現代日本を参考にした架空の町とする。歴史資料は住人の育った環境や生活制度を考える材料に使う。時代別の町を再現する機能は、その後の拡張として扱う。

## プレイヤーの役割

プレイヤーは町を見守り、住人が行動できる条件を少し変える。気になる人を追いかけ、本人の願いや困り事を知り、きっかけを作る。

| 操作 | 実行例 | 住人に残す判断 |
|---|---|---|
| 場所を整える | 二人掛けの椅子、共同作業机、居間の楽器を置く | 使うか、誰と使うか |
| 予定を提案する | 食事会、散歩、工房の開放日を提案する | 引き受けるか、参加するか、別の日時を出すか |
| 迷いを後押しする | 作品を見せる、友人に連絡することを促す | 自分に必要な行動か、今できるか |

提案には受諾、保留、辞退、別案の返答を用意する。実行には住人の時間、体力、所持金、相手の同意が必要になる。一人に対して有効にできる提案は一つ。同じ条件で断られた提案を重ねても効果を加算しない。

転職、同居、結婚、別れなどの重大な決断は、本人の願い、生活の見通し、相手の判断、これまでの経験から進む。プレイヤーはその前段階の機会を作る。

## 日常の遊び

暮らしを見る。気になる様子を見つける。その事情を知って働きかける。返答と生活の変化を見て、次にどう関わるかを考える。

例えば、近所の学生が壊れたラジオを持って工房の前を通り、職人は店内で自分の作品を作っている。共同作業机と開放日を提案すると、二人が会う機会ができる。

職人が教えることを楽しみ、学生が通い始める展開もある。職人が制作を優先し、開放を断る展開もある。学生が完成したラジオを大切にしながら別の進路を選ぶこともある。この違いを性格、予定、技能、記憶の組み合わせから作る。

予定が合わない場合も次の遊びにつなげる。「木曜の午後なら空いている」「大勢の集まりは疲れるが、二人なら行きたい」といった返答で、働きかけを考え直せるようにする。

## 時間と人生

同じ一時間でも、仕事を認められたい人、家族と話したい人、一人で休みたい人では意味が異なる。仕事にも達成、仲間、収入、生活の安定があり、家庭や交流にも喜びと負担がある。

時間は約束や勤務を扱う生活時計と、季節や加齢を扱う人生の暦で管理する。初期案は一日約3分、四季それぞれ3代表日で一年。生活週は7日で連続して数え、12日の年替わりで勤務曜日や習慣をリセットしない。この圧縮はゲーム用の仮設定で、移動と会話を見て理解できる速さを試作で確かめる。

一時停止、倍速、人物を追うときの低速観察を用意する。ゲームを閉じている間は時間を進めない。早送り中も予定、移動、双方の判断、関係の更新を同じ順序で処理する。

転居、卒業、勤務の変更、退職などによって、会える条件が変わる。住人がその予定を知っている場合は、別れの前に会おうとしたり、残された期間に取り組むことを選び直したりする。内部にある寿命の値を本人の判断へ直接渡さない。

## 3D表現

斜め見下ろしを基本とし、回転、ズーム、人物追従ができるドールハウス型の町にする。住宅や店の壁はカメラに応じて隠し、同じ場所で過ごす人々の距離や視線が分かるようにする。

人物は日本のJRPGを参考にしたアニメ調3Dとし、大人は5.5〜6.5頭身、子どもは4〜4.5頭身を制作時の目安にする。細めの顔の輪郭、アニメ調の目、束感のある髪、面で切り替わる陰影、明るい色彩で統一する。挨拶、相づち、ためらい、疲れた姿勢などを読み取りやすくし、年齢や体格には違いを付ける。[JRPG調の制作資料](../assets/artwork/v02-jrpg/README.md)を外見の基準とする。

| 読み取ってほしいこと | 動きの例 |
|---|---|
| 相手に関心がある | 顔を向け、作業の手を止める |
| 一緒にいると落ち着く | 隣に座り、それぞれの作業を続ける |
| 会いたいが今は忙しい | 相手を見る。進行中の作業を示して、別の時間を提案する |
| 私生活では休みたい | 帰宅後に上着を脱ぎ、静かな場所へ移る |
| 過去の出来事を覚えている | 相手の作品を見つけ、声をかける |

この対応は演出上の設計であり、現実の人の表情や姿勢を診断する規則ではない。人物ごとに表し方を変え、行動の履歴と合わせて意味を伝える。

## 振り返り

各人の人生には砂時計を添える。上部はすりガラスにし、下部には過ごした時間の色が積もる。色の層から、その時期の出来事や共有した記憶を開ける。

共通の人生点数は置かず、本人の願いと、それを追うなかで変わった暮らしを振り返る。誰かを見送ったあとも、教わった料理、修理した物、続いている集まりが町に残る。

## 制作の順序

最初は3世帯8人の日常を作る。家庭、店、工房、町外の勤務や学校の予定を持たせ、場所の変更と一つの提案で交流が変わるところまで確かめる。

次に、異なる場所での役割、約束の履行と修復、習慣、願いの変化を加える。その後、加齢、転居、退職、世代間の継承を接続する。

試作の評価は住人の名前や行動を覚えたか、提案する理由を持てたか、結果の理由を説明できたかで行う。設定値や調査との一致だけで、人物への愛着や遊びの面白さを判断しない。
