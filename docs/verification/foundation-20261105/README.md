途中の変化を確認するMacプレビューを `builds/foundation-preview-20261105-r3/` にビルドした。[出力と確認範囲](mac-preview.json)。独立した保存先を使い、書き出した実アプリで起動、停止・再開、人物追跡、＋ボタンのズーム、家全体への復帰、室内・外観の切替、人物の背景のスクロール、実ベッドでの睡眠、保存した調理途中への復元を確認した。外観へ切り替えると追跡中の人物に近い屋根だけが映る点と、ドラッグ回転の未確認を記録している。家族の造形や着座・就寝・道具動作は制作中で、段階1の完成判定にはしない。

## 空間と生活の接続

[正本の間取り](../../design/ogawa-home-layout.svg)から、8室、実開口、扉、寝床、台所、独立トイレ、洗面脱衣洗濯、浴室と庭の物干しを生成する。経路は壁・家具・人体の幅・立入許可・設備占有を考慮し、通れないときに直線で壁を抜けない。以前の[構造画面](home-structure.png)は初期の簡易形状で、現在の住宅アートとは異なる。

[家族と住宅アートの統合画面](household-art.png)は実GPUで確認した途中の画面。造作・床・台所・衛生設備・寝具・持ち物が同じ間取りへ載る。人物は既存モデル、家事と着座・睡眠の動作は未完成で、この画面だけを配布可能な家族生活の証拠にしない。

家族の意図を、実際の身体の移動、向き合わせ、到着、経過時間、生活工程へ接続した。食材→調理→配膳→食事→洗浄、洗濯機→干す→乾燥→片付けを資源として持つ。未実行の予定や移動だけでは欲求を回復させない。家族の誘いは子が応じて同じ場に到着してから進み、待ち続ける誘いは見直す。

家具の連続動作を接続する前に、`tools/foundation/inspect_household.gd -- --minutes=1440` で家・身体・経路・設備・生活判断の24時間を、物理時間刻みと生活時計の比率を保って逐次進めた。[統合記録](household-integration.json)。3人の出勤・通学・帰宅、食事・衛生・家事・家族の時間が進み、当該runでは表示対象の身体同士の重なりは観測しなかった。これは当時の短縮した計算実行であり、現在の家具動作を含む一日や、通常速度で24時間映像を目視した結果ではない。現在の観察ツールは実Skeleton更新を待つ形へ変更している。仕事・学校・買い物の外部施設は、この一戸では境界の抽象化であり、店内・校内を再現していない。

## 身体と保存

`ResidentMotor` は実秒とmで身体位置・速度・向きを連続更新し、角で減速して旋回する。分単位の位置の段差を見た目の追従で隠す方式を使わない。渚・亮・凛の既存rigへ、[QuaterniusのCC0素材](../../../assets/motion-sources/quaternius/INVENTORY.md)から歩行・着座等を転送し、AnimationTreeを実移動距離へつないだ。既存の造形そのものはこの転送では改善しない。出発・停止・旋回の支持足制御と自然さの確認は別途進行中。

`tests/test_resident_motor.gd` は移動・家具へ向く・保存再現、`test_home_navigation.gd` は29設備の到達・権限・占有と椅子移動後の実経路、`test_household_day.gd` は実行時間・資源・担当交代・保存を確認する。`test_foundation_world.gd` は実シーンの調理途中をJSON保存し、身体・工程・設備・扉・家具への出入りをまとめて再開する。実Skeleton更新を待って後続の進行を比較し、不正な状態で部分的に書き換わらないことを確認する。これらの成功は、自然な動作や楽しさの合格を意味しない。

## 次の家族版へ向けた統合候補

家族の背景・現在の選択を読む[人物画面](family-inspector.png)を追加した。[レイアウトの記録](family-inspector.json)は停止中の実シーンを2つのウィンドウ寸法で描画したもの。小川家の背景は家事・制作・誘いへの返答へつながり、他9人の背景と固有活動は新4住宅へ接続するための契約までを準備している。他9人の専門活動を実行した証拠とはしない。

食材・料理・食器・洗濯物は実在庫と工程から表示し、中断中の保持・実置戻し・担当交代・途中保存を扱う。物の移動と全身動作・指の接触を一連にする作業は未完了。新4住宅は実壁穴・ガラス・屋根・世帯別の設備まで空室描画した候補で、[森家の室内](mori-layout-candidate.png)は住民の生活や最終街並みの受入画像ではない。

寝床・椅子への連続した出入りを接続した。睡眠・勤務・通学は予定の区切りまで一度の利用を続け、進入・退出や未実行の時間を作業へ加算しない。途中復元の差を調べ、回転の繰返しで身体スケールが縮む処理を修正した。生活・設備・物の状態とmotorを比較し、骨poseの再計算差は距離・角度で確認する。大人と子どもの実ソファへの進入・使用・退出も確認し、短い下腿では座面が身体を支えて足が宙にある状態を床への接触と区別する。まな板・鍋・食器置場は、実メッシュと作業目標の一致を別に確認する。詳細ログは `builds/verification/family-checkpoint-r3-final2/`、`builds/verification/family-furniture-world-unit-scale/`、`builds/verification/continuous-family-routines-r2/`、`builds/g2-home-architecture/`、`builds/g3-background-carry/` に保持する。

## 配布前に残るもの

家族3人のJRPGモデル、自然な出発・停止・旋回、実家具への着座・起立と寝具への出入り、道具と物を扱う全身動作、背景が選択へ現れる生活、通常の実画面での一日、競合・遅延・途中再開の確認を残す。立った姿のままの睡眠や家事、瞬間的な着座を完成扱いにしない。

確認手順と生ログは `builds/verification/foundation-core/`、`builds/foundation-household/`、`builds/motion-retarget/` に保存する。SHA・ハッシュは素材やビルドの識別用であり、検査の合否や件数へ含めない。
