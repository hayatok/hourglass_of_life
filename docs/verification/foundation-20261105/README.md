# 生活基盤の再構築 — 段階1の着手

[ロードマップ](../../development-roadmap.md)の段階1は進行中。以下は住宅と移動制御の初期実装で、家族が一日暮らす完成版や配布ビルドではない。

間取りの正本から、複数室、壁と実開口、寝床、台所、独立トイレ、洗面脱衣洗濯、浴室をGodotへ生成した。[間取りの図](../../design/ogawa-home-layout.svg)と[JSON](../../../data/foundation/ogawa-home.json)は同じ配置を使う。Pythonで静的な開口・接近点・家具の干渉・扉を開いた場合の到達を確認し、実GPUで[構造の画面](home-structure.png)を確認した。[生成シーンの確認](home-inspection.json)は、開口を扉の板で塞がないことと、実家具・利用点の存在まで。居住者の生活や扉の利用手順を証明するものではない。

`ResidentMotor` は分単位の位置の段差と見た目の追従を使わず、実秒とmで位置・速度・向きを連続更新する。加減速、角での減速と旋回、停止と再開、入力の時間刻み差、保存再現の[制御確認](resident-motor.json)を行った。歩行素材、AnimationTree、足の支持、実ゲームでの自然な歩容はまだ接続していない。コントローラの数値的な成立を人物の見た目の完成とは扱わない。

新しい歩容素材としてQuaterniusの無料Standard原本とCC0ライセンスを保管し、実際の収録を確認した。[出典と実clip](../../../assets/motion-sources/quaternius/INVENTORY.md)。歩行・着座・立上りはあるが、専用の出発・停止・90/180度旋回は含まれていない。取得や解析はリターゲット・描画品質の合格ではない。

次は部屋と扉の経路・占有、基準rigへの実歩容、生活工程と設備の状態をつなぐ。モデルと内装も本制作へ進め、24時間の小川家の生活が成立した段階でMac版をビルドする。以前の制作・欲求の途中作業は復元可能な別ブランチへ保管し、細部の追加へ作業を戻していない。
