# 11月4日のモーション中間版

ユーザーの「キリのいいところでビルドし、その後は開発継続」に対応したローカル開発版。作業中のgame/data/settingsを専用sourceフォルダへ固定してrelease exportし、その後の指先・経路の修正とは分離した。版の識別は検査件数に含めていない。

配布物は `builds/playable-motion-checkpoint-20261104/命の砂時計.app` と `hourglass-of-life-motion-checkpoint-20261104-macOS.zip`。Universal x86_64/arm64、Godot4.7.2。Apple Siliconで起動し、新しい12人の町を開始した。

実際の配布アプリで、14:07の停止を保った拡大ボタン、住民一覧の検索、晴の選択、6種類の提案画面を確認。「一緒に遊ぶ」で晴と渚の名前と四目並べを確認して提案し、実際に受け入れられた。再開すると二人が机へ向かって遊び、19:17に止めて全景ボタンへ戻った。合成イベントや人物の状態差し替えは使っていない。アプリは確認後に終了した。

[25項目のパッケージ検査](packaged-ui.json)は実際のPCKから、4人のモデル/skin/animation/LOD、肖像と12人、1台のラジオと16駒、カメラの拡縮、遊びの提案、手帳、ベンチの取消し、日本語サポートデータを読み込んだ結果。失敗なし。Intelの実機確認、物理トラックパッドのジェスチャー、配布アプリ内での対局完了・保存再開はこの中間版では未確認。

この版の指先は改良途中で、把持目標はthumb/indexの基部中点を使う。指腹で36mmの駒を挟む処理、家具を避ける近距離経路、通常craftと盤・トレイの干渉確認はビルド後も継続する。完成版、全活動の破綻解消、人による楽しさの確認とは扱わない。GitHub Release/タグ/マージは行っていない。
