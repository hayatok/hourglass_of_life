# 12人の町の段階検証

2026年11月3日。住民間の接点を増やす要望を受け、v0.8の人口拡張の一部を前倒しした。通常の新規開始は12人。v0.5〜v0.7の未完了項目と、16人・24人の検証は残る。[開発計画](../../development-roadmap.md)、[Issue #14](https://github.com/hayatok/hourglass_of_life/issues/14)で継続する。

## 追加した暮らし

| 住民 | 仕事と生活時間 | 得意分野・関心と初期の接点 |
|---|---|---|
| 白井 咲・42歳 | 図書館の午前勤務 | 写真・模型。文と写真の知り合い |
| 瀬戸 晴・25歳 | 自転車修理補助の早番 | 修理・音楽。修や律と知り合い |

| 森 結衣・27歳 | 午後の音楽講師 | 音楽・交流。智との同居と、既存住民への少数の接点 |

技能、関心、勤務、収入、材料費、願い、次の願い、残す記録、退職と生涯の条件を[住民定義](../../../data/residents.json)から読む。初期関係は方向のある少数の知り合いから始め、町の全員が全員の技能を知る状態にはしない。既存の会話・紹介・共同制作・支援の成立判定を新住民にも使う。新しい行動や多数人の集まりを追加したという意味ではない。

住宅2棟に各2人の専用寝床・食事の席・机を置き、室内通路と既存の道へつなぐ。[住宅と外見の検査](population/environment-checks.json)は、予約、実際の移動、着席・睡眠、色と体格、LODの保持を確認する。住宅の寝食画像は条件を作った検査場面であり、無介入の生活記録とは分ける。

新4人の外見は既存モデルと骨格・衣服の形を共有し、服・髪の色と体格を変えた暫定版。固有モデルの造形を仕上げたとは扱わない。肖像は実モデルのGPU描画から作った。住人一覧には検索とスクロールを追加し、1280×800でも最後の人を選べるようにした。

## 無介入の交流

[人口別の観測記録](population/population-comparison.json)はseed 710・711・712を各3代表日、8人と12人で進めたもの。受諾した誘いではなく、実際に完了した会合をmeeting IDごとに1件として数える。完了時の両参加者の記憶signalと照合し、一覧の保持上限や同分の計画上書きによる集計漏れを避ける。

| 観測値・3条件の集計 | 8人 | 12人 |
|---|---:|---:|
| 実完了した会合 | 55 | 69 |
| 新旧住民の会合 | — | 15 |
| うち新旧住民の共同制作 | — | 5 |
| 1人日当たりの参加回数 | 1.53 | 1.28 |
| 3日間に会合参加がない住民 | 各条件0人 | 各条件0人 |
| 仕事・学校・睡眠と実会合の競合 | 0 | 0 |
| 家具の二重占有・非有限な状態 | 0 | 0 |

全員が実際に食事と睡眠を行った。交流の総数は増えたが、一人当たりの参加回数は減っている。勤務と睡眠を含めた観測時間は、8人で延べ103,680人・分、12人で延べ155,520人・分。そのうち空腹値が0.9を超えた時間は14,980人・分と20,816人・分、疲労値が0.9を超えた時間は2,579人・分と2,596人・分だった。いずれもゲーム内の仮の生活係数による状態を記録したもの。

8人のseed 711、12人のseed 711・712で世帯の生活費残高が負になった。参加の偏り、生活費、食事・休息の取りやすさは調整が必要。人数だけで交流や生活の受け入れを完了にしない。

追加住民の初期化でも乱数を消費するため、同じseedでも元8人の初回自由行動や以降の乱数の順序は異なる。共通住民の初期欲求・行動・乱数状態を記録しており、この比較は追加した接点だけの因果実験ではない。人間による試遊や面白さの証明も含まない。

別に、通常の12人でseed 710〜712を各最大3代表日まで進め、新旧住民の共同制作を画面で追った。710では期間内に完了せず、711で修と晴が13:53に相談・移動を始め、14:52に合流してラジオの作業を開始、15:37に完了した。修の修理技能は0.9から0.9025、晴は0.52から0.5344へ変わった。[同じプレイの記録](population/natural-collaboration.json)と[実作業の画面](population/natural-seed711-meeting_1-engaged.png)を残す。人物・予定・欲求・技能への介入は行わず、人物選択と追従カメラだけを操作した。有限探索で見つけた一例であり、発生頻度の推定には使わない。

## 保存と検証

開発中の版間セーブ互換は維持要件から外した。現行12人の保存、再開後240分の世界・知識・予定・家計・乱数の一致、不正な保存の拒否を確認する。8人の開始APIは既存の検査と人口比較のために残す。

[エンジン検証の記録](engine-checks.json)に、importとheadlessの26枠、GPUの7枠、ログ、最終ソースの指紋をまとめた。保存条件の保持、増えた家具・建物を対象にする検査、体格差による枕位置の補正を修正し、関連する検査を再実行した。家具は12人で217項目、街路は新2住宅を含む90方向で実壁との交差0件。全シーンの進行と、新住民の一覧・住宅・無介入制作はGPUでも確認した。

- [人口と保存の検査](population/population-checks.json)
- [人口別の観測工具](../../../tools/inspect_population.gd)
- [新住民の勤務・人生の検査](../../../tests/test_new_resident_life.gd)
- [住民一覧の操作検査](../../../tests/test_population_ui.gd)

新住民の退職・生涯の境界検査は、指定した時点へ状態を進めて規則を確かめるもの。全員の生涯を人間が遊んだという記録ではない。

次は、教わった人から第三者への協力、複数人が予定を合わせる集まり、会場と役割の分担へ進む。12人の生活費・移動・休息と参加の偏りを確認してから16人へ広げる。
