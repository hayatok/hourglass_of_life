# 検証記録の読み方

検査の根拠は、実際の操作と進行、状態の変化、描画、人物や家具との接触、保存と再開の結果に置く。骨・重み・クリップ・同梱ファイルなどの静的な構成確認は、動作や見え方の確認と分けて記す。件数だけで品質や面白さを判断しない。

SHA、画像の画素SHA、ファイル指紋は素材とビルドを識別する出自記録（provenance）に限る。検査・テストの合否や件数には含めず、その分を別の識別比較で埋めない。画像の描画回帰では実画素の差と見え方を確認し、何が変わったかを記録する。

2026年11月3日に集計を見直した。晴の実町記録は、従来の42件／43件からSHA照合5件を外した **headless37件／GPU38件** を機能検査として扱う。[現行記録](v0.5/haru-jrpg-gameplay/README.md)を参照。古いログや中間資料の当時の件数には識別照合が含まれる場合があり、現行の機能検査へ合算しない。過去の原記録は履歴として保持する。

実行時間には並行作業やマシンの負荷も影響する。重い処理と同時に採った時間を、処理速度の改善の根拠にしない。制作・描画・検証は順番に行い、完了したプロセスと不要になったブラウザタブを終了する。
