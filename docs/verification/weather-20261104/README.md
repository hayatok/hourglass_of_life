# 天候が自由時間の選択へ影響する初期実装

2026年11月4日。通信しない架空の気候を使う開発版。実測統計や現在の天気予報ではない。

## 実装

`data/weather.json` と `WorldWeather` で一季節3日・一年12日の晴雨・気温を進める。住民の判断用とは別の乱数、天候区間と次の切替、暦の対応を保存する。schema8のみを受け入れ、読み込み前に町の時計との整合を検査する。HUDや照明の更新で乱数を消費しない。

自由な休息・食事・交流・趣味・写真・記録を読む候補に、現在の雨、気温、予想される屋外時間、本人の特性から有限の負担を加える。屋根は実際の部屋の境界と活動スポットから判定する。屋内でも、そこまでの外出負担は残る。移動時間は直線距離による採点用の見積もりで、実際の移動は既存の道路・室内通路・家具回避を使う。町外の未制作の室内は判定不明として評価しない。

現在の天候を小さな町で直接知覚できるという仮定を置く。未来の天候や他人の私的状態は候補に渡さない。勤務・日課・先約、交流中の状態、切迫した空腹・疲労は採点より前に処理する。共同制作や盤遊びの誘いの場所変更・延期、体の濡れや温熱欲求、服装、傘、雨粒、物価・雇用・ニュースはこの初期実装には含まない。

## 条件比較

[行動の比較](behavior.json)は7人×128個の同じ判断用seedについて、同じ保存した人物・予定・家計を毎回復元し、その時点の晴れ/雨だけを変えた896組。新しい計画の提案はこの比較中だけ先送りした。341組で実際の活動または行き先が変わり、屋外選択は晴れ116回、雨87回だった。小標本12seedでは逆方向に出たため、初期の12件だけを傾向の根拠には使わなかった。雨でも屋外を選ぶ余地を残している。

変更した一例では、選択後に実際の `_assign` が作る経路を `_move` で最後までたどり、屋内の目的地へ到着した。これは移動処理の確認で、時間経過を含む自然発生の試遊とは分けている。

途中の町を実ファイルへ保存し、天候・人々・二つの乱数・約束・物を復元して、同じ先の経過になることも比較する。数値はJSON保存時の丸めを許容し、乱数の文字列はそのまま比較する。表示用の状態や識別用のSHAを、これらの動作確認の代わりにしない。

## 回帰確認

[全体の結果一覧](all-engine-checks.json)は40本のheadlessスクリプトと関連GPU実行を、記載した複数の実行記録からまとめたもの。一続きの全件実行が最初から成功した記録ではない。88代表年、生活・認知・約束・支援、物と盤、接触・経路、人口、実UIなどを含む。追加した不正RNG文字列と小数時計の拒否、四分刻み/一括進行、外部fixture時計変更はfocused検証で補った。

最初の全体実行では、seed711の3代表日の観察内に智の通常会話を取得できず[失敗した](natural-three-day-failure.log)。会話を制作中の会話で代用したり、住民を強制参加させたりせず、同じseed・同じ町を7代表日（勤務週）まで観察する条件へ変更した。頭の向き、話し手/聞き手、挨拶の手の動きなどの基準は維持。実際には5643分で全対象の条件がそろい、headless/GPUとも成立した。[当初の不足と再観察](natural-observation.json)。これは会話等の描画確認で、人が遊んだ感想や面白さの実証とは分ける。

## Mac配布物の確認

`builds/playable-weather-20261104/hourglass-of-life-weather-20261104-macOS.zip` と同フォルダの `命の砂時計.app`。ビルド元のproduction codeは `4b633880769904c17d240813a1de2d4f92019eac`（識別情報）。Godot4.7.2 release export、Universal x86_64/arm64。後の文書・CI成果物保持の変更は配布対象のruntimeを変えていない。過去の中間版とモーション版も別フォルダに保持している。Release/タグ/マージは行っていない。

[実際のPCKの確認](packaged-ui.json)は32件成功。4人のmesh/skin/clip/LOD、実指腹データ、12人の肖像、1台のラジオ/16駒、提案・ノート・配置、拡縮と天候表示・照明の接続を確認した。SHA/ハッシュは識別記録で、機能の合否や件数に含めていない。

実際のMacアプリを起動して新しい12人の町を始めた。自然生成された雨の13:14を確認し、町が動いてから14:31で停止した。[雨の町](native-rain-paused.jpg)。メニューの「保存する」で実際にschema8、12人、天候と乱数、1台のラジオと16駒が保存された。[保存画面](native-saved.jpg) / [保存内容の概要](native-save-summary.json)。

「保存したところから再開」で町を開くと、雨20.3℃・14:45と再開通知が見えた。そのまま生活が進み、16:26・雨16.9℃で停止した。[再開後の画面](native-loaded-paused.jpg)。再開直後から実操作中も時間が進んだ観察で、14:31の停止状態を保ったまま再開した証拠とはしていない。完全な経過再現は上記のファイル保存・状態比較で別に確認している。

確認前に元のプレイヤー保存2ファイルをローカルへ退避し、確認用アプリの終了を確認してから復元した。退避した保存とテストの完全な保存は公開していない。自分で起動したゲーム・Godotの確認用プロセスは終了した。Apple Siliconでの実操作であり、Intel実機と物理トラックパッドのジェスチャ、人による初見の試遊は未確認。
