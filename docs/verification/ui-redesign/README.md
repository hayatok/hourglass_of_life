## 実画面から見つけて修正したこと

初回の実ウィンドウ操作では、OptionButtonを開くと元の大きな肖像がメニューの行へ出て、数人しか見えない問題が残っていた。閉じたボタンの縮小だけでは足りなかった。PopupMenu側の各画像幅を32、一覧の高さを420以下へ制限し、実GUIから開いて末尾を選ぶ経路を追加した。[開いた一覧](../ui-rebuild/proposal-partner-popup.png)では、11人が平均約46pxの行高でスクロールできる。

後から決まった約束も「約束の一覧」で日時順に読めるようにした。別案では「この日時で約束する」を主ボタンにし、戻る操作は「保留して戻る」と区別する。日本語の折り返し言語を指定した。配布テンプレートでは編集環境の辞書が自動では使えないため、[Godotの公式設定](https://docs.godotengine.org/en/stable/classes/class_projectsettings.html#class-projectsettings-property-internationalization-locale-include-text-server-data)に従ってText Serverの辞書・行分割規則もパッケージへ同梱する。編集環境の画像だけで配布物の日本語表示を受け入れない。

旧肖像の欠落、同じ大きさのボタン内でアイコンが消える問題、選択後も残る初回案内、ベンチ設置後に消える選択状態、modalを開く前の右ドラッグが残る問題も修正した。同じ時刻の記録では共有体験の内容を優先して要約し、活動名と相手を読めるようにした。全文はその人物の出来事へ開ける。
