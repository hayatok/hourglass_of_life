## 実際の配布アプリで確認した操作

ZIPから展開したアプリを起動し、新しい12人の町を開始した。エージェントが画面を見てマウスとキーで操作し、以下の実際の結果を記録した。検査専用の人物状態や返答へ差し替えていない。

1. 14:56に時間を止め、一覧から咲を選択。本人のカードと追跡を確認した。
2. 「咲に提案する」から「会話に誘う」を選択。スクロールできる顔付きの一覧で晴を選び、二人の名前を含む実行ボタンを確認した。[確認画面](native-proposal-confirm.jpg)
3. 実行すると、晴は既に誰かと過ごす予定があるため保留した。実際の返答が同じ画面に残った。[晴の返答](native-proposal-reply.jpg)
4. 別の提案から智を選んで実行した。今はベンチが使われているため、咲から「今日17:00・25分・広場のベンチ」という別案が出た。[相手の確認](native-tomo-confirm.jpg) / [別案](native-tomo-reply.jpg)
5. 「この日時で約束する」を押し、受け入れられた返答を確認した。[確定後](native-proposal-accepted.jpg)
6. 町へ戻り、人物手帳の「約束の一覧」に智との17:00の会話が残ることを確認した。元の停止状態も14:56のまま保たれた。[約束の一覧](native-promises.jpg) / [町へ戻った画面](native-town.jpg)

最終パッケージにはText Serverの日本語辞書・行分割規則を同梱した。別案と受け入れ後の実際の文章で、「今日」や句点だけが別行へ押し出される以前の表示が解消したことを確認した。
