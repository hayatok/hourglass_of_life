# 命の砂時計 — 生活と人生の基盤から作り直すロードマップ

2026年11月5日改訂。暮らせる空間、自然な身体動作、理由のある人生を先に作る。通常のゲーム画面を見れば前の版との違いが分かる規模を、一つの開発区切りとする。

目指すのは、背景も望みも異なる人々が、家・家族・仕事・町の条件の中で暮らし、その選択が他の人の人生にも残るゲーム。温かいJRPG調の人物と街並みに、台所・衛生設備・私室・家計・就労のある生活を成立させる。初期の生活制度は日本に近い小都市を基準に固定し、他地域の統計は定義と条件を確認して取り込む。

## 最初に作る一戸と、一日の生活

- **家**：家族3人が暮らせる複数室の家。台所に冷蔵・保管、流し、加熱、作業台を置き、食卓・食器・寝具・収納をそろえる。廊下から衛生設備へ行けるようにし、他人の寝室を通路にしない。
- **身体**：基準の1体で自然な歩幅、重心移動、加減速、足の置き直し、旋回、着座と起立を作り、親2人と子どもへ展開する。移動位置と足の周期を一つの制御へそろえる。IKは動作そのものを作る主役にせず、床・家具・道具との差を補う。
- **暮らし**：食材を出す→調理→配膳→食べる→洗う。トイレ・浴室の占有、身支度、洗濯、仕事・学校、家族の相談と睡眠を実設備へ接続する。入浴・排泄の私的な部分は扉と省略で扱い、利用前後と生活上の結果を表す。
- **背景**：渚の働き方と家族の時間、亮の受注と育児、凛の学校と模型を、過去の出来事・部屋・持ち物・現在の行動へつなぐ。開始時の家族史は創作として明示し、開始後の経験と混同しない。
- **見ること・働きかけること**：家を見渡す・人物を追う・生活の続きをたどる操作を用意する。プレイヤーは分担や交流の機会を提案でき、住民は受諾・別案・辞退を返す。

普通の速度の実画面で「出発→歩く→曲がる→止まる→座る→立つ」と「朝から夜までの家庭生活」を連続して確認する。壁抜け、瞬間的な座面移動、誰も作っていない食事の出現、使っていない設備による欲求回復を残したまま完成扱いにしない。

## 統計と人物の人生を結ぶ

世界の資料から、人生に起こりうる経路と、地域・年代・年齢・世帯条件による違いを調べる。国連人口推計、OECD家族・住居・生活時間、UNESCO教育、ILO雇用、WHO健康・死亡、日本の生活時間を参照する。[調査と採用規則](life-course-evidence.md)

統計は町の構成や結果の分布を調整する材料にし、各人の過去・願い・能力・機会・相手の意思を経て出来事が成立する。世界平均を一人一人の毎日の確率にせず、国・年代・分母・推計と予測・状態と遷移を分ける。「結婚しない」「子を持たない」「働き方を変える」「戻って学ぶ」人生も成立させる。

例：子が生まれる→夜間の世話が増える→勤務と家事を相談する→保育や親族へ支援を頼む→家計と住居を考える。このように、事象を家族や第三者へ広がる生活の連鎖として作る。人物紹介文やランダムなニュースを増やすだけでは段階4を満たさない。

## 作り直す基盤

建物→部屋→扉→設備→物の所在を管理し、行動を「選ぶ・相談する→経路を決める→近づく・向く→使う→片付ける・退出する→経験が残る」の共通工程へそろえる。人物名ごとの特別処理から、世帯構成・予定・技能・履歴で動く処理へ移す。

生活時計、身体の移動、長期の人生進行の尺度も再設計する。通常観察では自然な身体の速さを保ち、年月を進める時は日付送りと振り返りを使えるようにする。早送りのために全員の手足だけを不自然に速く動かさない。

人物モデル、Tripo原型、素材、関係・個人知識、物の所有と予約、保存の仕組みは品質を確認して引き継ぐ。現在の住宅の構造、歩行と家具利用の制御、名指しの人生イベントは必要に応じて置き換える。旧開発セーブの互換は維持しない。

## 各ビルドで示す成果

1. 通常のゲーム画面で分かる変更と、その版で遊べる生活を示す。
2. 同じカメラで前後を比較し、連続した生活と動作を実ゲームで確認する。
3. 食材・道具・設備・関係・人生の変化と、途中保存からの再開を確かめる。
4. 自動検証の件数や版番号だけで品質向上を説明しない。SHA・ハッシュは識別情報に限る。
5. Macで動く成果物を残して次の段階へ進む。重い制作・検証は順番に行い、終了した自身のプロセスとTripoタブを閉じる。
