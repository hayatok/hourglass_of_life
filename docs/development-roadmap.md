# 命の砂時計の開発計画

完成目標は、8人が自分の事情と意思で暮らすJRPG調3Dの人生シミュレーション。プレイヤーが場所や予定を整え、住人の返答、関係の積み重ね、年月による人生の変化を見届けられるゲームとして仕上げる。

Godot 4.7を使用する。町、住人、家具、UI、アニメーションを保存されたシーンとリソースに分け、シーンエディタで配置や調整ができる構成にする。画像資料をゲーム画面の代わりに置かず、実際の3D空間で住人が移動して行動する。

## バージョンごとの中心

| 版 | 中心となる要素 | 完了を判断する体験 |
|---|---|---|
| v0.1 日常ときっかけ | 8人の日課、移動、観察、提案と返答、利用可能な場所 | 人物を選び、その事情に合う働きかけと反応を確かめられる |
| v0.2 関係と記憶 | 方向のある関係、共同体験、約束、別案、習慣 | 同じ操作でも相手と過去の経験で結果が変わり、それを説明できる |
| v0.3 仕事と家庭 | 収入、仕事の喜び、家事や世話、支援、個人の目標 | 人柄だけでなく生活の条件によって選択が変わる |
| v0.4 年月と人生 | 加齢、転居、退職、願いの変化、継承と別れ | 時間の区切りが行動を変え、誰かの経験が町に残る |
| v0.5 人物の表現 | JRPG調モデル、相互行為のアニメーション、音と演出 | 行動、視線、姿勢から、本人と相手の様子を読み取れる |
| v1.0 完成版 | 一連の進行、保存と復帰、導入、安定性、配布 | 新規開始から年月の変化まで遊び、保存して続きを再開できる |

各版では中心となる遊びを成立させることを優先する。装飾や小さな見た目の変更だけで版を進めない。進行不能、データ破損、操作の誤認など、その版の体験を妨げる問題は同じ版で直す。

## 完成条件

- 町と住人が3Dで描画され、8人が予定、欲求、責任、関係から自律的に行動する。
- 働きかけには受諾、保留、辞退、別案があり、実際の移動と参加が成立した交流だけを記憶する。
- 仕事、家庭、一人の時間、交流にそれぞれ意味があり、共通の人生点数を最大化する遊びにしない。
- 関係と経験が次の行動につながり、年月による役割や目標の変化と、残された物や習慣を見届けられる。
- メニュー、HUD、観察、場所の変更、振り返り、設定、保存、再開が一つのゲームとしてつながる。
- 歩行、会話、共同作業、着席、休息などを、人物と相手の状態に対応した動きで表現する。
- JRPG調の制作資料を基準に、実際にゲームへ組み込む人物と町のモデルを仕上げる。
- Godotのシーンエディタで実際に編集し、保存されたシーンをゲームでも使用する。
- GitHubのIssue、Milestone、コミット、リリースで進捗と検証結果を追える。
- 実機での操作と複数日の進行、保存と再開、配布物の起動を確認する。

v0.1の仮モデルや簡略化した生活は途中の実装であり、完成条件の代わりにしない。
