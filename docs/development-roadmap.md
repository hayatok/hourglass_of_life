# 命の砂時計のロードマップ

個性と生活歴の異なる住民が自分で暮らしを選び、出会い・協力・すれ違いから町が変わる人生シミュレーションを作る。プレイヤーは気になる人を見守り、場所・道具・交流の機会・負担の分担に働きかける。

## 作る順序

| 順序 | 作るもの | 遊びの中で起きること |
|---|---|---|
| 1 | **欲求・気分と日常行動**：自律性、有能感、刺激、短期の気分。一人の回復、静かな同席、練習、教え合い | 同じ状況でも人物ごとに選び方が変わり、経験によって次の過ごし方も変わる |
| 2 | **物を使う生活モーション**：制作の材料・工具・作りかけ・完成品、受け渡し、作品を見せる動作。着席・起立・食事・寝起きのつながり | 手元と相手の反応を見て、何をしているか、何ができたかが分かる |
| 3 | **季節・天候と服装**：季節で変わる町の景観、雨の表現、上着・収納・着脱・濡れ・乾燥・洗濯、屋内への誘い直しと延期 | 雨や暑さ・寒さで、準備、服、行き先、会う相手や時間が変わる |
| 4 | **買い物・家計・供給**：店の品揃え、価格、在庫、入荷待ち、見積り、購入・修理・代用品・共同購入 | 同じ値上がりや品不足でも、持ち金・技能・愛着・予定によって対応が分かれる |
| 5 | **関係と集まり**：作品の共有、相談、紹介、複数人の集まり、恋愛・親密さと私的な動機、断りや距離の取り直し | 二人の経験が第三者の機会へ広がり、関係の変化がその後の暮らしに残る |
| 6 | **仕事・地域行事・世界の出来事**：求人・応募・勤務の相談、催しの準備・参加・片付け、供給事情の変化、掲示・ニュース・伝聞 | 人によって知る情報と時期が異なり、町の外の変化も仕事や交流へ波及する |
| 7 | **16人・24人の町**：異なる生活歴・世帯・職業の住民、住宅・寝床・店・交流場所、混雑時の譲り合い | 生活時間や技能の異なる人が出会い、協力相手や集まりの組合せが広がる |
| 8 | **経験が残る人生と町**：経験から変わる願い・習慣・役割、入居・成長・転居・退職、作品・記憶・技能の継承 | 誰と何を経験したかで人生が分かれ、去った人の営みが次の住民へ受け継がれる |
| 9 | **完成版の遊び始めと継続プレイ**：導入、操作・表示・音量の設定、砂時計からの振り返り、保存管理、配布パッケージ | 初めてでも観察と働きかけを理解し、気になる人物の続きを遊べる |

1と2を一緒に進め、続いて3へつなぐ。12人の暮らしと交流を深めてから増員する。公式統計・ニュースの調査は並行し、ゲームへの取り込みは対応する生活機能と組み合わせる。

## 次に作る一連の遊び

1. **教わるか、自分で進めるかを選ぶ**。布小物づくりに、上達したい気持ち、自分で完成させたい気持ち、教える側の余裕をつなぎ、実演・練習・手伝い・断りを選ぶ。
2. **作品を暮らしへつなぐ**。布の色・柄と作品の種類、使う・贈る・感想を聞く行動、材料の補充を用意する。同じ工程の反復から、用途と相手による選択へ広げる。
3. **雨の日の過ごし方を選ぶ**。上着を用意して出かける、屋内へ誘い直す、別の日にする、濡れた服を干す。約束相手も自分の事情から返答する。

この三つに使う人物・道具・場所・動作・UIを一緒に仕上げ、その後に制作や生活行動の種類を広げる。

## 行動を増やす仕組み

「目的・動詞・物と道具・相手と役割・場所・状況・工程」を追加できる行動カタログを作る。住民は本人の欲求、個性、技能、知識、予定、経験から組み合わせて計画する。

| 分野 | 追加する行動の例 |
|---|---|
| 身の回り | 着替える、洗う、干す、畳む、片付ける、調理する、食べる、休む |
| 制作と学び | 材料を探す、作る、修理する、練習する、実演する、教わる、作品を見せる |
| 交流と遊び | 声をかける、静かに同席する、誘う、遊ぶ、相談する、紹介する、集まりを開く |
| 助け合いと関係 | 頼む、手伝う、差し入れる、断る、分担する、予定を変える、関係を話し合う |
| 仕事と町 | 買う、借りる、注文する、応募する、交渉する、催しを準備する、出店する |

新しい物・役割・環境が増えるたびに、行動と計画の組合せを広げる。各行動には準備・移動・実行・結果・片付けと、中断した場合の続け方を持たせる。隠れた動機は行動や返答に表し、成人の私的な行動は双方の意思と年齢条件を扱う。

## 全段階で仕上げるもの

- **人物と町のグラフィック**：空の軌跡を参考にした可愛いJRPG調へ全住民と街並みを統一。顔・髪・体格・衣服・表情、家や店の持ち物、季節ごとの景観を作る。
- **ゲームUIと操作**：気になる人・関係・出来事の続きへ移れる画面、意図と結果が分かる提案、文字サイズやカメラの設定。Macのトラックパッドだけで全景と近景を行き来できる操作を仕上げる。
- **音と反応**：足音、工具、衣擦れ、雨、店や集まりの環境音、作業の完了や相手の返答に合う演出をそろえる。
- **プレイヤーの働きかけ**：共有道具、交流の場所、集まりの機会、生活の支援を用意できるようにする。住民は受け入れ・別案・辞退を自分で選ぶ。
- **動作と進行の安定**：体格や衣服に合う接地・把持・家具との接触、混雑時の移動、遠景の描画、保存・再開を整える。
- **外部資料の取り込み**：気象・物価・家計・雇用・地域案内・世界の供給事情を、出典と対象期間を持つデータパックへまとめ、行動の条件へ接続する。
