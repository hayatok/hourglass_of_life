# 統計から生活史と出来事を作る

2026年11月5日。以下は確認した一次資料と採用する設計方針。資料一覧を追加したことを、ゲームが統計に基づいて動いている証拠にはしない。データパックの取得・変換・動作への接続はロードマップの各段階で実装する。

## 資料と生活への接続

| 資料 | 対象・時期・使う内容 | 作る生活・出来事 | 採用時の条件 |
|---|---|---|---|
| [国連 World Population Prospects 2024](https://population.un.org/wpp) | 2024年版。国・地域、年齢、出生、死亡、人口構成。過去の推計と将来予測を区別 | 出生、加齢、世帯の世代構成、親との死別、町の人口変化 | 個人の死亡年齢を平均寿命に固定しない。将来値は選んだシナリオ付きの予測として保存 |
| [OECD Family Database](https://www.oecd.org/en/data/datasets/oecd-family-database.html) | 家族構成、独立、出生、婚姻・離婚、親の就労。項目と国によって基準年が異なる | 実家からの独立、共同生活、同居、家族形成、子育て、別離後の住まい、再婚 | 状態の割合と年間件数を混ぜない。粗婚姻率・粗離婚率を、交際中・婚姻中の二人の遷移確率にしない |
| [OECD 住居費と所得 HC1.2](https://webfs.oecd.org/els-com/Affordable_Housing_Database/HC1-2-Housing-costs-over-income.pdf) | 2025年10月更新、主に2024年または直近年。家賃・住宅ローン・住宅関連費と可処分所得 | 住居の選択、同居、引っ越し、光熱費、修繕、仕事と通勤の選択 | 家賃だけの系列と光熱費等を含む系列を区別し、費用を二重に足さない。国ごとの調査単位・年をそろえる |
| [OECD Time Use Database](https://www.oecd.org/en/data/datasets/time-use-database.html) | 2026年更新。15–64歳、国ごとに異なる調査年。有償労働・学業、無償労働、身の回り、余暇 | 調理、片付け、洗濯、買い物、育児、介護、通勤、学びと休息の時間競合 | 乳幼児・高齢者へ成人平均を当てない。日記調査の対象と分類差を記録。全員に平均時間の日課を配らない |
| [総務省 2021年社会生活基本調査](https://www.stat.go.jp/data/shakai/2021/kekka.htm) | 2021年調査。A票は2022年8月、詳細行動のB票は同年12月公表。年齢・就業・世帯等で生活時間を比較 | 日本に近い初期生活圏の朝夕、身支度、食事、家事、育児、就業・学業 | 分類と対象年齢を表ごとに確認。感染症流行期の時点差を恒常的な生活の法則にしない |
| [UNESCO GEM Report 2026](https://www.unesco.org/reports/gem-report/en/2026) | 主に2024年の就学・修了、学齢、教育段階・地域による差 | 入学、進級、進路、職業教育、休学、中退、復学、大学と家族負担 | 卒業・結婚・就職を全員共通の一本道にしない。学制と教育機会を採用地域に合わせる |
| [ILO Employment and Social Trends 2026](https://www.ilo.org/publications/flagship-reports/employment-and-social-trends-2026) | 2026年1月公表。雇用、失業、働きたい人の雇用ギャップ、仕事の質。予測を含む | 初就職、求職、失職、再就職、転職、再訓練、労働時間・収入の変化 | 失業率の分母は労働力人口。非就業と失業、推計と予測、全人口との割合を分ける |
| [国連 International Migrant Stock 2024](https://www.un.org/development/desa/pd/content/international-migrant-stock/) | 2024年版、2025年公表。出身地・居住地・性別等の国際移民の居住ストック | 留学、就労移住、家族合流、帰国、送金、交友関係と住居の再形成 | 年間の転入率や国内転居率として使わない。一部地域の外挿とデータ欠測を保持する |
| [WHO Global Health Estimates](https://www.who.int/data/global-health-estimates) | 現公開系列は2000–2023年。年齢・地域・性・原因別の死亡、障害、疾病負担、寿命 | 病気、受診、回復、慢性症状、身体機能の変化、住居改修、介護、看取り、死別 | 健康寿命を発病年齢、疾病負担をそのまま発症確率へ変換しない。診断と日常で必要な支援・可能な行動を分ける |
| [Eurostat Housing in Europe 2025](https://ec.europa.eu/eurostat/web/interactive-publications/housing-2025) / [OECD 住居の混雑](https://www.oecd.org/en/data/indicators/housing-overcrowding.html) | 世帯人数、住居形態、居室数、世帯構成を考慮した空間不足。EU等の地域資料 | 家族向け住宅、個室のある共同住宅、子の独立後の余った部屋、高齢世帯の住み替え | 欧州の平均を町の設計基準へ直輸入しない。台所・浴室の数え方と寝室・居室の区別を確認する |

## 統計からゲームへの変換

資料のURL・版・取得日・対象年・地域・年齢区分・分母・単位・調査定義・欠測・推計/予測・利用条件を保存する。その上に、架空の町へ採用した制度、変換、調整係数、校正結果を別に記録する。

1. **初期の町**：年齢、世帯、学業・就業、住居・所得の組合せを作る。全員に世界平均を与えず、一つの生活制度の中で異なる事情を持たせる。
2. **本人の履歴**：創作した過去と、ゲーム開始後に起きた事実を区別する。過去の世話、成功、失敗、転居、別離が現在の知識・技能・関係・習慣・持ち物へ残る。
3. **発生する機会**：年齢や状態に合う求人、進学、転居、支援の必要などを提示する。年次の出来事を毎分再抽選せず、曝露時間と条件を管理する。
4. **本人と相手の選択**：願い、内面、生活の責任、利用できる物・場所、相手の意思から返答・別案・辞退を選ぶ。性別や属性だけで個人の役割を固定しない。
5. **実生活の変化**：選択後に実際の準備・移動・行動が成立して、家計・時間・住居・関係・健康・履歴を変える。未実行の予定を体験として記憶しない。
6. **結果の比較**：複数の人口・世帯・seedで、分布と生活の成立を比較する。平均だけでなく孤立した人、世話の偏り、機会のない人、過度な不幸の連続を調べる。

## 最初の三つの連鎖

- **子の成長と働き方**：入学・通学→放課後の予定→親の勤務との衝突→分担や他者への相談→子の自立→親の働き方の再変更。
- **失職と再就職**：仕事の契約終了→家計の見直し→求人を知る→応募・訓練→採用または別の選択→通勤・家事・住居への影響。
- **療養と家族の支援**：身体状態の変化→受診・休養→勤務や家事の相談→本人が受け入れた支援→回復または継続する支え→家族の休息や関係の変化。

出生・親密さ・婚姻は本人たちの意思と状況を扱い、全員に必須の成功条件にはしない。死去は人生の履歴と残された人の暮らしへつなぐ。いずれもイベント文を追加するだけで完了にしない。
