全案で、玄関と廊下から他人の寝室や作業室を横切らず独立トイレ・洗面脱衣・浴室へ行ける。共用設備と私物、個室の許可、浴室・トイレの一人利用を分けている。夜勤の遮音や隣人への音の伝わり方は、部屋を離しただけで成立したとは扱わない。

寝室とLDKは外壁の採光窓、浴室は高い曇り窓を持つ。共同住宅・北・森のトイレは内側配置なので、外窓ではなく廊下側の高い曇り採光窓を明記し、機械排気の設計を未完条件にしている。各家の切妻屋根、食卓上の照明、机や収納に置く物の意図もデータ化したが、3Dの造形・遮光・換気を検証したものではない。

## 正本と再生成

正本は [data/foundation/homes](../../../data/foundation/homes) の四つのJSON。`house.id` / `house.household` と `rooms` / `walls` / `doors` / `fixtures` / `residents` は既存の `LivingHouse`・`HomeNavigation`・`HomeOccupancy` と同じ構造。家具外形は世界軸の実寸、`interaction_point` は立位の接近点で、椅子や寝床の最終身体位置ではない。

各住宅の原点は北西外角 `(0,0,0)`、Xは東・Yは上・Zは南。南側ポーチの `house.street_connection.approach` が街側への接続点。`world_placement:null` は新しい街区での配置が未決定であることを表し、旧街の狭い住宅モデルへ重ねるための座標ではない。外部ゾーンは玄関ポーチまでで、通勤・通学先を代用しない。

リポジトリのルートからPython標準ライブラリだけで実行できる。

```sh
python3 tools/foundation/validate_home_plans.py
python3 tools/foundation/validate_home_plans.py data/foundation/homes/saeki-home.json --no-svg
```

四案すべてについて、部屋の囲い壁、開口位置、戸袋、家具外形、扉の開閉余白、全員の固有寝床・食卓席、必要設備を検査する。体半径0.24mの静的な平面モデルで、各室の全接近点と、各住民に許可された設備までの玄関からの接続も検査する。窓は部屋と壁・上下寸法・向き・扉との非重なりを検査する。図の破線はこのモデルから再生成した候補線。SHAや画像の出力成否は検査に数えない。

## 次の受入れ

この段階は2D設計と静的幾何の確認。Godotでの実経路・3D表示・動く扉の葉・人同士のすれ違い・家具への出入り・24時間の暮らし・保存再開は未確認である。建物の外形、設備支持面と人体の到達、扉の途中開閉を次に実シーンで確認する。

接続前に、`HomeArt` の小川家固定の窓・照明・壁作品と、`FamilyHistory` の小川家専用定義を世帯別に扱う必要がある。机や練習室の存在だけで縫製や音楽の動作が実装済みになったとは扱わない。

実生活の受入れでは、各世帯の全員が自分の寝床で休み、調理・配膳・洗い物・衛生・洗濯へ実移動する一日を追う。律の夜勤明けの睡眠、共有設備の待機と許可、智の仕事が食卓を占拠しないこと、成人親子や同居人の個室に無断で入らないことを画面と状態の両方で確認する。
