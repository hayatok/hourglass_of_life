# 最初の再構築 — 小川家の一日

## 目に見える完成像

三人の家族が、生活設備のある複数室の家を使って一日暮らす。普通のカメラで、誰がどこへ行き、何を使い、誰を待ち、どう助けたかが分かる。ここを段階1の家族版の到達点にする。街路、店内・学校・診療所を使う生活は、続く段階2で作る。[全体ロードマップ](../development-roadmap.md)

## 一戸の家

間取りの正本は `data/foundation/ogawa-home.json` とし、図・3Dの室内・経路・設備を同じ定義から作る。単なるラベル付きの広い箱へ戻さない。

- 玄関と靴・外出用品の置場。街路と廊下をつなぐ入口。
- LDK。保管と冷蔵、流し、加熱、作業台、三人の食卓、ソファと家族の物。
- 親の寝室と凛の個室。人ごとの寝床、着替え、収納、凛の勉強と模型。
- 独立トイレ、洗面脱衣・洗濯、浴室。廊下から利用し、寝室を通路にしない。
- 亮の在宅仕事の場所。食卓の食事と勤務が競合するなら、片付けや場所の相談として扱う。

壁・開口・扉・部屋の接続を実空間として持つ。家具には実寸・占有範囲・近づく位置・使う向き・利用者と物の場所を持たせる。トイレと浴室、個室の公開範囲を扱い、利用中は待つ、別の支度を先にする、許可を求めることができる。

## 三人の背景から一日の選択を作る

以下は初期設定として執筆する創作の家族史。統計から個人の経歴を推定したものではない。実装時は、事実の時点・当事者・本人が知る範囲・現在への影響を人物データへ入れる。

- **渚**：パンづくりの経験を重ね、子が学校へ上がる時期に家族との時間を取れる働き方を選んだ。自分の季節のパンを形にしたい一方、繁忙期の仕込みと家の時間が衝突する。作業ノート、以前の失敗の記憶、家族との約束が行動へ影響する。
- **亮**：継続案件を得ようとしている在宅デザイナー。仕事の期限と放課後の世話を担ってきた経験を持つ。収入を増やしたい日も、凛との模型を投げ出したくない。机、受注の記録、家事の分担と凛への期待を結ぶ。
- **凛**：小学校へ通い始め、家族と作る模型から、自分で考えて作ることへ関心が広がっている。昨日助けてもらったこと、学校で見聞きしたことが今日の遊びや相談相手を変える。個室の道具と作品が少しずつ変わる。

背景の文章を表示するだけでなく、「先に帰った人が食事の準備をする」「期限がある日は別の人に頼む」「子が自分で片付け、親が見守る」まで実際の予定と設備利用へつなぐ。

## 人物と住居のアート基準

最初の家族三人と住宅から、温かいJRPG調へ作り直す。既存のTripo原型と制作済み素材を参考に、顔・髪・体格・衣服の見え方、家具と人物の縮尺、屋根・窓・壁・床・照明の基準をそろえる。台所や浴室も箱の記号のまま完成にせず、用途と生活感が分かる形に仕上げる。部屋の持ち物は本人の仕事、子の成長、家族の過去を表す。

間取りと動線を先に3Dで確認し、その空間へ本制作の建材・家具・人物を載せる。設計確認用の簡単な形状は完成版のグラフィックに数えない。最初の家族で見た目と暮らしを両立してから、他の家と人物へ展開する。

## 身体と生活時計

通常の1×で、歩幅・足の接地・腰の移動と進行速度が一致する連続移動へ置き換える。出発、歩行、速歩、減速、停止、左右90/180度旋回、家具へ向く、着座、起立を同じ制御で扱う。体格や衣服の違いを高速再生と極端に小さい足振りで吸収しない。

移動の位置を一分ごとに飛ばして表示が追いかける構造をやめ、身体の位置・速度・進路を一つにする。経路が塞がった時は、壁を横切る直線を返さず待機・迂回・中止を返す。通常の身体の速さと、生活時計・作業時間・長期の日付送りを別に調整し、徒歩で隣室へ行くだけで朝の予定を使い切らない。

全身の動作を先に作り、手足のIKは現物の床・椅子・流し・道具との位置差を補う。既存モデルは残すが、歩行の素材・リグ・衣服変形に問題があれば作り直す。

## 最低限つなぐ暮らし

- 起床、寝具から出る、着替え・洗面、トイレ、外出と帰宅。
- 食材の保管と取り出し、下ごしらえ、調理、配膳、三人の食事、食器の回収と洗浄。
- 学校と勤務、在宅の仕事、子の世話、家事の分担と辞退、家族と静かに過ごす時間。
- 入浴前後、衣類を洗う・干す・しまう、私室の休息と就寝。

この段階で入浴や料理の全種類を増やさない。一種類でも、実物と準備・実行・片付け・効果・中断がつながった日常を作る。個別の飾りの種類は、成立した暮らしを展開する際に増やす。

## 実ゲームでの受入

1. 通常1×の一続きの画面で、5–10mの歩行、90/180度旋回、停止、着座と起立が自然に見える。足の接地開始・終了を含めて滑りを観察し、停止後の漂い、座面への瞬間移動、壁・家具抜けを残さない。
2. 家族三人の通常判断で24時間を通す。勤務・学校・世話と、食事・衛生・睡眠が設備と動作で成立する。
3. 同時にトイレや浴室を使おうとしても占有は一人。個室の立入と待機の理由が画面から分かる。
4. 帰宅の遅れ、食材不足、設備の混雑の各条件で、作業の担当や順序が変わる。実行していない食事・衛生・体験による回復や記憶を付けない。
5. 料理・運搬・入浴前後の途中で保存し、再開しても物・占有・家計・経験を増やさない。
6. 家族を初めて見る人が、誰が何をしていて何を待つのか理解できるか確認する。自動検査だけを自然さや楽しさの証明にしない。

間取りの図、データ、3Dの設計確認用シーンだけではこの段階の完了にしない。上記の暮らしを通したMacアプリをビルドして、次の街区へ進む。
