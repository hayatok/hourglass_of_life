# 住宅から温かいJRPGの街区へ

現5住宅は室内と設備を成立させる建築基盤。街区の最終アートとしては未受入とする。次は**街路に面した暮らし、建物の輪郭、玄関から敷地へのつながり**を一体で設計する。以下は調査と次の制作案であり、改修済みの報告ではない。

## 現外観の診断

比較対象は [5住宅の空室レビュー](../../builds/g2-home-architecture/review.json) の外観5枚。窓の数は室内向け採光窓を除く南側の外窓で、玄関扉は含めない。

| 住宅 | 街路側の現実装 | 原因 |
| --- | --- | --- |
| 小川 | 南の外窓1枚、洗面脱衣室 | 居間の主窓は西。正面は家族の居場所より水回りと物干しが目立つ。 |
| 佐伯 | 南の外窓1枚、趣味室 | 一部に暮らしは見えるが、LDK側の大きな正面壁が連続する。 |
| 三人の共同住宅 | 南の外窓0枚 | 個室窓を北、LDK窓を西へ集めた間取りと立面の設計。 |
| 北の共同住宅 | 南の外窓0枚 | 正面は玄関・道具室・洗面。道具室の窓も西にあり、南東からは見えない。東の高窓は俯瞰と軒の重なりで小さく見える。 |
| 森 | 南の外窓1枚、LDK | 縫製室の窓は西で、正面から仕事室の用途を読み取りにくい。 |

無窓の主因は描画漏れではなく、**室内だけで決めた開口配置と街路の向きの不一致**。[LivingHouse](../../game/foundation/living_house.gd) は定義された窓を実壁穴と固定ガラスにしており、既存の実レイ検査でもガラスと壁穴は成立した。ただし街路からの採光・遮蔽・用途の読みやすさの合格を意味しない。

全棟が約98〜134m²の単一矩形平屋、壁高2.65mで、屋根勾配も定義値から約15〜17度。`LivingHouse._build_roof()` は家全体に一枚の切妻、`HomeArt._roof_details()` は長い横筋を繰り返すため、幅の大きな金属板のように読める。5棟の色差だけでは建物の輪郭は変わらない。現参照実装は一階の部屋群と `AStarGrid2D`・単一床高を前提とし、二階を描くだけでは実生活空間にならない。

## 制作する建築kit

以下の寸法は本作の初期案。参照画像から実測した値でも、建築法規への適合値でもない。各部は同じplanから形・支持面・衝突・経路を生成する。

| 部位 | 構造から変える内容 |
| --- | --- |
| 建物の塊 | 主棟＋短い張り出し＋低い玄関つなぎの組合せ。幅4〜6m程度の屋根単位へ分け、L字・妻入り・段違いを作る。凹凸を実室・廊下・敷地の形と対応させる。 |
| 屋根と軒 | 勾配30〜40度を起点に、小さな瓦・スレートの重なり、棟、破風、厚い鼻隠し、軒裏の垂木を組む。軒0.45〜0.65m。小屋根と母屋は実際に納まり、玄関を覆う。 |
| 玄関ポーチ・庇 | 奥行1.4〜1.8mの奥まった入口、柱・梁・庇・靴を扱う場所を一組にする。通りから入口が分かり、開扉・待機・運搬の実空間が残る。 |
| 基礎 | 石・左官の基壇と木部の境を作る。地盤・床・玄関の高さを揃え、佐伯家は街路から段差なしを優先。見た目だけの段や、経路が無視する階段を作らない。 |
| 街路側立面 | 先にLDKや作業場所を通りに向け、実室に対応する窓・出窓・窓台を並べる。外壁の連続した無開口部分は3m程度を見直し目安にし、私室・水回りは高窓や奥まった配置で守る。 |
| 材質 | 温かい左官、石の基壇、木の柱・腰板、瓦/スレートの役割を分ける。横筋の屋根と一色の壁から、材の大きさ・縁の厚み・接合を読める面へ。均一な汚しや強いツヤで埋めない。 |
| 敷地と道 | 玄関前の小さな溜まり、低い境界壁、側庭、物干し・搬入の実用動線まで設計する。門から玄関まで最低1.2m、共有の歩行帯は1.5〜1.8mを起点に実体幅で確認。敷地は同じ芝の矩形台座を並べる形式から改める。 |

## 世帯ごとの発展と実装順

**最初の制作は北の共同住宅の建て直し。** 咲の個室・共用の食事側を街路に開く棟、晴の個室・水回り側の棟、低い玄関つなぎでL字を作る。玄関側の道具室は作業窓と独立した短い屋根を持つ。室内配置・開口・屋根・庇・敷地を一緒に再設計し、現在の大きな南壁へ窓を貼るだけの更新にはしない。家具、私物の所有、本人の予定と使用許可は引き継ぐ。

佐伯家は短い夜間動線と段差なしの平屋を残し、小さな趣味室の張り出しと深い軒で分節。小川家は家族のLDKが通りへ向く平屋と、私室側の短い棟に分ける。森家は生活棟＋実際に使う縫製棟を屋根のある通路で結び、仕事と来訪の入口を読める形にする。

三人の共同住宅は二階建てを候補にする。1階に共用LDK・水回り、2階に三個室と独立トイレを置き、律の昼の休息を共用部から離す。採用前に `floors/volumes`、階段の上下portal、階層つき経路、実昇降・旋回・床支持、階別cutaway、保存再開を実装する。用途のない上階や、外だけ二階・中は別サイズの建物を完成扱いにしない。二階が必要な世帯と平屋が適する世帯を混在させる。

データ拡張の単位は `house.volumes`（実footprint・floor_y・wall_height・roof）、`rooms.level/volume`、`porches/canopies`、`thresholds/stairs`、`plot.public_edge/paths/utility_yard`。現1階planの実寸とIDを接続基盤に使う。北の一棟を灰色の構造で確認→同kitで隣接3棟と約30mの通りを作る→材質と光を揃える→世帯別の生活を通す→必要な二階住宅へ進む。

## 次の受入れ

- 色・看板・植木を外した状態で、二翼の輪郭、庇、基礎、玄関の奥行きが分かる。街路の目線高1.6mと通常のゲーム俯瞰の両方で比較する。人体寸法の基準を置き、巨大な小屋に見える比率を再評価する。
- 通りから居室/作業窓が見え、その窓の先に対応する実室がある。枠・庇・屋根が開口を覆わず、実レイと実画面が一致。換気、遮音、プライバシーの効果は別に検証する。
- 住民が通り→ポーチ→玄関→寝床・台所・トイレへ実移動し、開扉待機・持ち物・家具接触・保存再開が成立。佐伯家は段差なし、共同住宅は相手の個室を通らない。二階を採用した場合は実昇降を含む。
- 同じkitの3棟が輪郭と入口の位置で区別でき、道・前庭・作業入口が連続する。人にラベルなしで入口や共用/私的空間を指してもらう短い画面試験を行う。人による確認はまだ実施していない。

この調査では新しいGodot/Blender/GPU描画やcore変更を行っていない。既存の空室画像と一次資料の比較であり、街区の最終品質・遊びやすさの実証ではない。
