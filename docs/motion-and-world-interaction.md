# 行動が街と噛み合うモーションの設計

2026年11月3日。「作る、運ぶ、遊ぶ、会話などが、街との相互作用も含めて破綻なく動き、見ているだけで楽しい」という要望をv0.5以降の受け入れ条件へ具体化する。**以下の共通工程、運搬、遊び、活動別の細かな操作は未実装**。JRPG調の形と動きを保ち、意図、重さ、接触、相手の反応、行動の結果が読み取れることを目指す。

進捗は[Issue #19](https://github.com/hayatok/hourglass_of_life/issues/19)、モデルの制作は[Issue #17](https://github.com/hayatok/hourglass_of_life/issues/17)と対応づける。

## 現在の差

移動、会話、共同活動、食事、睡眠は実際の町へ接続されている。家具には進入位置、接触位置、手の目標、席の予約があり、手足の位置を合わせる処理もある。一方、次の不足がある。

- 制作6種類には目的や技能・結果の違いがあるが、見た目は主に共通の`work`と、机上の両手を小さく上下する処理である。
- 会話では頭を向けて挨拶するが、話す番、聞く番、間、胸・首・視線の連動は十分でない。
- カップを手元へ追従させる表示はあるが、街の物を拾い、所有し、別の場所へ運んで置く共通の仕組みはない。
- 趣味・共同制作はあるが、順番や遊具・駒などの状態を伴う「遊ぶ」行動はない。
- 着席・起立、持ち上げ・置くなどの接続動作、衣服や寝具、混雑の仕上げが不足している。未確定の足接地調整も完成扱いにしない。

主な対象は `resident_avatar.gd`、`resident_contacts.gd`、`contact_rotation.gd`、`activity_spot.gd`、`activity_places.gd`、`activity_layout.tscn`。行動の成立と効果は `simulation.gd`、`resident_activities.gd`、`work_family.gd`、`resident_agenda.gd` と対応づける。

## 共通の工程と、物・場所との約束

行動を「近づく→向きを合わせる→準備する→手を伸ばす→つかむ・接触する→扱う→離す→片付ける・離れる」の工程へ分ける。すべての行動が全工程を必要とするわけではないが、省略した工程と成立条件を定義する。

| 定義するもの | 持たせる内容と守る条件 |
|---|---|
| 人物の役割 | 作業する人、支える人、受け取る人、話す人、聞く人、遊びの手番。相手が来ていなければ共同動作を開始しない |
| 場所 | 進入経路、立ち位置・座席、向き、人数、作業面、退出位置。見えている家具と同じ配置から読む |
| 対象の物 | 街に存在する物のID、置き場所、向き、状態、持ち主、現在の保持先、予約者。取り出し元と置き先を持つ |
| 接触 | 左右の把持点、指の形、手首の向き、支点、足の支持、視線の目標。物の大きさと体格に合わせる |
| 工程 | 準備・実行・確認・終了の区切り、長さ、繰り返し、役割交代、途中で止められる箇所 |
| 成立イベント | つかむ、置く、受け渡す、加工する、手番を終えるなどの時点。見た目と世界の事実を同じ工程へ結ぶ |
| 取消しと復帰 | 手を離す、物を安全な場所へ戻す、予約を解放する。中断・保存・読込・モデル変更後も人物と物の状態を再構築する |

物は、一つの街の物として存在し、棚、机、人物の手のいずれに保持されるかを一意にする。持ち上げたときに棚の複製が残る、手元へ別の物が出現する、置く前に持ち物が消えることを避ける。受け渡しも二人へ同時保持させず、受け取れる位置と空いた手を確認して保持先を移す。

持ち主、今の保持先、利用予約は別に持つ。人の道具を借りて運んでも持ち主は変わらず、贈るなどの行動が成立したときだけ所有を移す。保存するのは物と参加者のID、所在、工程、役割、予約、適用済み効果であり、描画ノードの参照ではない。

アニメーションだけで加工品、材料、得点、交流の成立を増やさない。実行条件と工程の成立を世界側で決め、モーションはその状態と同じ対象を扱う。物・席・道具の予約と、本人の勤務や世話の責任をまとめて確認する。

## 行動ごとに見える違いを作る

| 行動 | 一連の動き | 街・相手に残る変化 |
|---|---|---|
| 修理・制作 | 道具を用意する、片手で支える、もう片手で操作する、手を止めて確かめる、相手に見せる、片付ける | 実物の部品・作りかけ・完成状態。教える人と試す人の交代 |
| パンの試作 | 材料や皿を用意する、こねる・形を整える、置く、見比べる | 材料と試作品の状態。調理と待ち時間を同じ手の上下動で表さない |
| 写真・録音 | 写真を取り出して選ぶ、示す、相手が見る。録音は操作する人と演奏・確認する人を分ける | 選んだ写真や実際に完成した記録。存在しない写真・演奏を台詞だけで作らない |
| 運ぶ | 元の場所へ行く、足を止める、構える、つかむ、持ち上げる、運ぶ、置き場へ向く、下ろす、離す | 一つの物の所在と保持先が移る。荷物に応じて片手・両手、姿勢、歩幅、通れる幅が変わる |
| 卓上の遊び | 道具を広げる、座る、自分の番を待つ、選んだ駒やカードへ手を伸ばす、動かす、相手が反応する、片付ける | 実際の手番と盤面。考える、喜ぶ、悔しがる、もう一度誘う違い |
| 屋外の遊び | 相手や物を見る、狙う、投げる・打つ、追う、受ける・拾う、返す | 遊具や物体の位置、参加と退出。最初は一種類に絞って接触と経路を確かめる |
| 会話 | 相手へ向く、話す人へ視線を送る、聞く、相づち、間を置く、話す番を渡す、別れる | 実際に交わした話題・経験。両者が同じ周期で手を振り続けない |
| 食事・休息 | 椅子に向く、腰を下ろす、食器を持つ、口元へ運ぶ、戻す、手を空けて立つ | 席と食器の所在、食事や休息の時間。飲み終える前に歩き出さない |

各動作には、開始の構え、力を使う部分、余韻を持たせる。持つ物が変われば重心、肘、指、歩幅も変える。顔や手の細かな動きだけでなく、骨盤・胸・肩・首・視線を役割に合わせて連動させる。会話しながらの作業などは、使う手・視線・姿勢が競合しない組合せに限る。

表情や反応は[欲求・内面と行動](needs-and-behavior-design.md)につなぐ。同じ制作でも、自信がない人は確認を多くし、慣れた人は短く確かめる。聞き手の余裕や気分によって相づちや退出の仕方が違うようにする。見た目の違いは本人の状態・経験から作り、理由のない小動作だけを増やさない。

## 接地、接触、遷移を成立させる

- 歩行は実際の移動距離と足の周期を合わせ、支持中の足の滑り、方向転換、停止直前を測る。旋回や大きな位置補正では足の固定を解除し、古い場所へ脚を引っ張らない。
- 手は対象の表面・把持点と向きを合わせ、指、手首、肘、肩の届く範囲を確認する。届かなければ体や立ち位置を調整し、腕を伸ばして取り繕わない。
- 荷物と身体を合わせた通行幅を扱う。戸口、机、椅子、ほかの人物に荷物や身体が突き抜ける経路を選ばない。混雑では待つ、譲る、持ち替える、別経路を探す。
- 着席・起立、拾う・置く、寝る・起きるを独立した接続動作にする。既存の完成姿勢への補間だけで済ませず、足・腰・手の支持と家具の実位置を確認する。
- 体格、成長後の姿、服や髪の違いを対象に含める。子どもの踏み台、裾、袖、長い髪と道具・椅子・寝具の干渉を、実際の動作の途中でも確認する。
- 中断時は手・物・場所の状態が整ってから次へ進む。相手が離れた、道具が使えない、退出経路が塞がった場合も、空中の作業や存在しない相手への動きを続けない。
- 死去・退居などで本人が片付けられない場合は、描画の終了を待たず、世界側が定めた安全な保管先へ物を一度だけ移し、保持・予約・役割を解放する。置き先が塞がっていても終端を持ち、除去された人物へ物や予約を残さない。

足や手の位置を合わせる処理は、実際に見えるスキンの結果で評価する。目標点が正しい、骨名がある、クリップが再生されたという確認だけでは、接触や動作の品質を受け入れない。

## 時間、保存、距離による見え方

生活上の工程と、描画用のクリップの時間を明示的に対応づける。停止中は工程を進めず、カメラは動かせる。低いフレームレートでも、つかむ・離すなどの成立イベントを飛ばしたり重複適用したりしない。

高い倍速では短い小動作を省略しても、物の所在・持ち主・保持先、参加条件、予約、実際の作業結果を保つ。省略した表示を、その細かな動作が通常速度でも完成している証拠にはしない。

保存には必要な物・所有・行動工程・予約・相手との役割を含め、途中から同じ状態を構築できるようにする。描画距離でモデルを切り替えても、握っている物、姿勢、視線、工程を失わない。画面外でも物と行動の結果は同じように進み、再び近づいたときに二重の道具や置き去りの物を作らない。

## 実装の順序

| 段階 | 一緒に完成させる場面 | 進む条件 |
|---|---|---|
| 1 共通の基盤 | 足の支持と停止・旋回、把持点、物の一意な所有、工程と中断。晴ともう一人、工房一室 | 近づくところから手を空けて離れるまで連続して確認できる。顔・手・道具と実物の状態が一致する |
| 2 作る・運ぶ | 棚の材料を取り、台へ運び、二人が役割を分けて修理・制作し、完成品を見せて戻す | 実際の場所を経由し、同じ物を扱い、材料・工程・成果・技能・記憶が実参加に対応する |
| 3 会話・遊ぶ | 作業の手を止めて話す、相手が見る・応じる。卓上の遊びで準備・手番・反応・片付け | 固定の同時ループにせず、相手・対象・結果が分かる。退出・保留も破綻しない |
| 4 全体へ展開 | 修理、模型、パン、写真、録音、手芸、屋外の遊び、食事と休息へ広げる | 12人と成長後の姿、家具や場所の違いでも同じ契約で動く。活動固有の意味が見える |

まず一室で完成度を確かめ、共通の仕組みを保って街へ広げる。行動候補に名前を追加しただけ、静止画で道具を持たせただけでは、その行動を完成扱いにしない。既存の操作不具合と人物品質のP0課題も維持する。

## 受け入れと試遊

同じ場面を開始から終了・退出まで連続して追い、以下を確かめる。条件を固定した工程の比較と、通常の町で自発的に選ばれた行動を両方用意し、どちらの記録かを明記する。

| 見るもの | 具体的に確かめること |
|---|---|
| 接触と重さ | 支持中の足のワールド位置のずれ、手と把持点の位置・向き、物と手の相対的なずれ、腰と椅子、衣服・道具の干渉。許容差は対象の寸法に合わせて決める |
| 物と工程 | 元の場所→手→置き先で同じ物が一つだけ存在。つかむ・離す・加工の時点と、保持先・材料・成果の更新が一致する。借りて運ぶだけで持ち主を変えない |
| 相互行為 | 相手が来る前に始めない。話す/聞く/作業する役割と視線・反応が対応。渡せない相手へ無理に受け渡さない |
| 中断と競合 | 辞退、疲労、別の予定、二人が同じ道具を欲しがる、置き先が塞がる、相手が退出する場合。保持中の死去・退居と保存再開も含め、物と予約を失わず次の行動へ戻る |
| 再現と条件差 | 拾う途中、運搬中、受け渡し前後、遊びの手番中の保存・再開。体格、LOD、30/60fpsと一時的な負荷、通常速度・停止・倍速を変える |
| 街での読み取り | 近景と通常距離で、何をしているか、何を持つか、誰へ何をしようとしているか、結果がどう変わったかを見て説明できる |
| 見守る楽しさ | UIの説明を閉じた短い試遊で、気になる動きや人物を追いたくなるか、次の動作を予想し、結果や反応を楽しめるかを見る |

状態の検査、実スキン・接触の測定、実ゲームでの連続操作・目視、人の試遊を区別して記録する。静止画は途中の姿勢の根拠に限り、動きの滑らかさや時間のつながりを証明したとはしない。SHAやハッシュは素材・ビルドの識別だけに使う。

現段階はこの仕様の追加であり、工程付きの運搬・遊びや、全活動の破綻解消を実装・検証した結果ではない。
