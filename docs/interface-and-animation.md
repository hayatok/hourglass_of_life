# メニューと画面と動きの設計

画面の中心を住人の暮らしに空け、選んだ人の事情と、働きかけへの応答を読み取りやすくする。UIは濃い藍、生成り、落ち着いた金色を軸にし、町の光や人物を邪魔しない。

## メニュー

タイトルには「はじめから」「つづきから」「設定」「操作案内」「終了」を置く。保存がない場合は、つづきからを選べないようにする。開始時には8人と町の紹介を短く示し、最初に誰を追うかを自由に選べる。

ポーズメニューから保存、設定、操作案内、タイトルへ戻る操作を行う。新規開始や上書き保存で既存データを失う場合だけ、結果を示して確認する。通常の観察や提案で確認ダイアログを重ねない。

## HUD

| 場所 | 表示と操作 |
|---|---|
| 上部 | 年、季節、日、時刻、一時停止、1倍・3倍・6倍の進行 |
| 左側 | 住人8人の一覧。選ぶと追従と詳細表示へつながる |
| 中央 | 3Dの町。選択中の人物を控えめな輪で示す |
| 右側 | 名前、年齢、仕事、今の行動、その理由、次の予定、欲求、願い |
| 右側の切替 | いま、関係、記憶の各画面 |
| 下部 | 直近の出来事と、場所を整える操作、振り返り |

人物の上の表示は短い名前や一言を基本にし、全員の数値を常時並べない。空腹、疲労、静かな時間の必要などは、何を表す値かを文章でも示す。

## 働きかけ

住人を選んで「誘ってみる」「休む時間を作る」「取り組みを後押しする」といった提案を選ぶ。日時、相手、使う場所が必要な場合は、その条件を同じ画面で指定する。

提案後には本人が知っている事情を返す。辞退や保留の場合も「今は仕事」「疲れている」「二人なら会いたい」「別の日時なら空いている」など、次の働きかけを考えられる応答にする。

場を整える操作では、使える位置へベンチや作業場所を置く。入口、移動経路、必要な席数を確認し、置けるかを表示してから決定する。置いた瞬間に交流が成立したことにはしない。

## カメラと操作

左クリックで人物や物を選ぶ。右ドラッグでカメラを回し、ホイールでズームする。WASDまたは画面の移動操作で町を見る。人物一覧から追従を切り替えられる。

Spaceで進行を止め、Escapeでメニューを開く。操作案内はゲーム中にいつでも見直せる。UIの上で操作したときは、背後の町へ入力を通さない。

## 演出

選択、提案への返答、共同体験、季節の変化を、それぞれ違う短い音と控えめな表示で伝える。拒否を警告音や赤い失敗画面だけで表さない。

重要な会話を追うときは、カメラと時間をゆっくりにできる。視線や相づちを見せる時間を取り、長い文章を読むために現実の時間制限を設けない。

人生の振り返りでは、砂時計の層から、その時期に会った人、続けたこと、作品、約束を開く。別れの演出は残された人と物へつなげ、共通の点数で人生を評価しない。

## アニメーション

| 状態 | 動きと成立条件 |
|---|---|
| 待機 | 呼吸、視線、姿勢。休止中も大きく動き続けない |
| 移動 | 歩行と方向転換。移動速度と足の周期を合わせる |
| 挨拶 | 相手へ顔を向け、手を上げる |
| 会話 | 相手を見る、相づち、身振り。双方が合流してから始める |
| 共同作業 | 手元を見る、見せる、受け渡す。人数分の位置を確保する |
| 着席 | 椅子へ近づく、座る、過ごす、立つ |
| 食事 | 座る、食べる、合間に話す |
| 休息と睡眠 | 力を抜く、横になる、起きる |

GodotのAnimationPlayerと保存されたアニメーションリソースを使い、シーンエディタから再生と調整ができるようにする。移動、上半身、顔と視線は独立して扱える構造にする。

仮モデルの動きで行動とタイミングを検証し、完成用の人物リグへ差し替える。ゲームの実際の行動を決める処理と、見た目の再生を分ける。
