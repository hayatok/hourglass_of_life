# メニューと画面と動きの設計

画面の中心を住人の暮らしに空け、選んだ人の事情と、働きかけへの応答を読み取りやすくする。UIは濃い藍、生成り、落ち着いた金色を軸にし、町の光や人物を邪魔しない。

## メニュー

タイトルには「はじめから」「つづきから」「設定」「操作案内」「終了」を置く。保存がない場合は、つづきからを選べないようにする。開始時には12人の住民一覧を開き、最初に誰を追うかを自由に選べる。

ポーズメニューから保存、設定、操作案内、タイトルへ戻る操作を行う。新規開始や上書き保存で既存データを失う場合だけ、結果を示して確認する。通常の観察や提案で確認ダイアログを重ねない。

## HUD

| 場所 | 表示と操作 |
|---|---|
| 左上 | 年・季節・日・時刻 |
| 右上 | 住民を選ぶ、出来事を見る、年月を振り返る、メニュー |
| 左の引き出し | 肖像と名前による住民選択・名前と仕事の検索 |
| 中央 | 3Dの町。選択中の人物を輪と短い名前で示す |
| 左下 | 選択人物の肖像・名前・行動・状態、近くで見る操作、本人への提案、人物手帳 |
| 中央下 | 時間の停止・再開、進行速度。停止したまま速度を変更できる |
| 右の引き出し | 明示的に開く人物手帳。いまの暮らし、約束の一覧、人間関係、思い出、家計・仕事 |
| 右下 | 建物の見え方と町の整備。整備を開くと共有予算と配置費用を表示 |

2026年11月3日にHUDと提案の流れを作り直した。[再設計の理由とリサーチ](ui-redesign.md)を参照。人物を選ぶだけでは詳細を全画面へ展開しない。
人物の上の表示は短い名前や一言を基本にし、全員の数値を常時並べない。空腹、疲労、静かな時間の必要などは、何を表す値かを文章でも示す。

## 働きかけ

住民カードの本人名を含む「提案する」から、休息、願いへの応援、会話、手助け、共同制作を選ぶ。二人の提案は次の画面で相手と内容を確認して送る。返答と具体的な会話の別案も同じ画面に残す。提案画面を開いている間は町の時間を止め、閉じると元の停止・進行状態へ戻す。

提案後には本人が知っている事情を返す。辞退や保留の場合も「今は仕事」「疲れている」「二人なら会いたい」「別の日時なら空いている」など、次の働きかけを考えられる応答にする。

場を整える操作では、使える位置へベンチや作業場所を置く。入口、移動経路、必要な席数を確認し、置けるかを表示してから決定する。置いた瞬間に交流が成立したことにはしない。

## カメラと操作

左クリックで人物や物を選ぶ。右ドラッグでカメラを回し、ホイールでズームする。WASDまたは画面の移動操作で町を見る。選択人物のカードから追従を切り替えられる。

Spaceで進行を止め、Escapeでメニューを開く。操作案内はゲーム中にいつでも見直せる。UIの上で操作したときは、背後の町へ入力を通さない。

トラックパッドではズームできないという実プレイの報告を受け、ピンチ拡縮、二本指でのパン、画面上とキーによる代替をP0の修正計画へ加えた。これは未実装である。[入力と配布アプリでの受け入れ条件](ui-redesign.md#macのトラックパッドへの対応計画)を参照する。

## 演出

選択、提案への返答、共同体験、季節の変化を、それぞれ違う短い音と控えめな表示で伝える。拒否を警告音や赤い失敗画面だけで表さない。

重要な会話を追うときは、カメラと時間をゆっくりにできる。視線や相づちを見せる時間を取り、長い文章を読むために現実の時間制限を設けない。

人生の振り返りでは、砂時計の層から、その時期に会った人、続けたこと、作品、約束を開く。別れの演出は残された人と物へつなげ、共通の点数で人生を評価しない。

## アニメーション

| 状態 | 動きと成立条件 |
|---|---|
| 待機 | 呼吸、視線、姿勢。休止中も大きく動き続けない |
| 移動 | 歩行と方向転換。移動速度と足の周期を合わせる |
| 挨拶 | 相手へ顔を向け、手を上げる |
| 会話 | 相手を見る、相づち、身振り。双方が合流してから始める |
| 共同作業 | 手元を見る、見せる、受け渡す。人数分の位置を確保する |
| 着席 | 椅子へ近づく、座る、過ごす、立つ |
| 食事 | 座る、食べる、合間に話す |
| 休息と睡眠 | 力を抜く、横になる、起きる |

GodotのAnimationPlayerと保存されたアニメーションリソースを使い、シーンエディタから再生と調整ができるようにする。移動、上半身、顔と視線は独立して扱える構造にする。

仮モデルの動きで行動とタイミングを検証し、完成用の人物リグへ差し替える。ゲームの実際の行動を決める処理と、見た目の再生を分ける。

## 行動の始まりから終わりまで

[モーションと街の相互作用](motion-and-world-interaction.md)に、制作・運搬・遊び・会話の工程、道具の把持、物の保持先、相手の役割と反応、中断・保存・倍速の条件を追加した。これは未実装の拡張仕様である。既存の`work`などを再生できることに加え、近づく、構える、実物へ触る、扱う、離す、片付ける、退出する一連の動きを受け入れ対象にする。通常距離でも目的と結果が分かり、観察して先を見たくなることを試遊で確かめる。
