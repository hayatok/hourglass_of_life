# 命の砂時計のキャラクター行動仕様

住人は身体の状態、価値観、役割、生活上の制約、相手との経験から行動を選ぶ。公的統計は生活時間を比較する基準、行動科学は行動を組み立てる考え方として使う。数値の係数と更新式はゲーム用の仮設定とする。

出典のR番号は[調査資料](research-notes.md)に対応する。設定案は[行動モデル](../data/behavior-model.json)、架空の住人例は[初期住人](../data/residents.json)を参照する。

## 住人の状態

| 項目 | 内容 | 更新の時期 |
|---|---|---|
| 基本情報 | 年齢、同居人、技能、仕事、移動に必要な条件 | 加齢や生活の節目 |
| 性格傾向 | 外向性、協調性、勤勉性、否定的感情の生じやすさ、開放性 | 通常は緩やか |
| 大切にするもの | 達成、安心、他者の世話、創作、つながり、自分で決めること | 重要な経験のあと |
| 欲求 | 空腹、疲労、つながりの不足、自律性の不足、有能感の不足、静かに過ごす必要 | 生活の進行中 |
| 一時的な状態 | 快・不快、活発さ、緊張 | 直近の経験や休養 |
| 役割と責任 | 勤務、家事、育児、介護、学業、引き受けた約束 | 予定と交渉に応じる |
| 個人の目標 | 次の一歩、進み具合、締切、続けたい理由 | 経験と節目 |
| 習慣 | 行動と手掛かりの組、繰り返しやすさ | 同じ状況での反復 |
| 記憶 | 起きたこと、相手、自分の受け止め、記録された時刻 | 出来事の発生時 |
| 相手との関係 | 親しみ、信頼、気楽さ、残っている期待、共有した記憶 | 交流や約束の結果 |

性格傾向と価値観は0〜1の連続値として扱う。それぞれが独立した項目で、合計を1にする必要はない。欲求は0が満たされた状態、1が不足の強い状態を示す。性格の値で行動を禁止せず、行動候補の見込みに小さく反映する。[R06、R07]

つながりの不足と静かに過ごす必要は同時に生じうる。この場合、親しい一人との散歩や、同じ部屋で別々のことをする時間が候補になる。どの活動が両方に効くかはゲーム用に定める。

性別や年齢から家事への意欲、仕事への熱意、社交性を自動決定しない。本人の生活歴、現在の責任、利用できる支援、相手との合意を個別に持たせる。幼い子どもの生活時間は10歳以上を対象とする統計の平均値から生成しない。[R01、R02]

## 行動の選択

生活時計の進行に応じて欲求と予定を更新し、行動の完了、状況の変化、一定の再考時刻で次の行動を選ぶ。

1. 現在の場所、本人が知る予定、欲求、目標、利用できる物から候補を挙げる。
2. 到達できない場所、使えない設備、払えない費用などで実行不能な候補を外す。
3. 相手が必要な行動は、その人に依頼し、参加の可否を待つ。
4. 実行可能な候補について、欲求、目標、関係、役割、習慣、楽しさ、負担を見積もる。
5. 得点の近い上位候補から、保存可能な乱数状態を使って一つを選ぶ。
6. 物や場所を予約し、移動してから行動を始める。実際に成立した効果を記録する。

初期の採点式は次のとおりとする。各項目は0〜1にそろえ、負担だけを差し引く。研究から推定した式ではない。

    基礎得点 =
      0.26 × 欲求が満たされる見込み
    + 0.20 × 本人の目標や価値観との一致
    + 0.16 × 相手との関係や期待との一致
    + 0.10 × 現在の役割との一致
    + 0.08 × 状況に結びついた習慣
    + 0.08 × 楽しさの見込み
    - 0.12 × 時間や体力や金銭の負担

性格、一時的な状態、過去の経験は各項目の見込みに反映する。例えば、人前で話す負担は一律の外向性だけで決めず、その相手への慣れや準備にも依存させる。[R05、R06、R07]

最も高い基礎得点との差が0.12以内にある候補を集める。提案の加点後の得点で上位3件を残し、温度0.08のsoftmaxで選ぶ。これらの数値も仮設定。選択した行動と乱数状態を保存し、再現時に毎フレーム振り直さない。

進行中の行動は一定のまとまりまで続ける。ゲーム内10分を再考間隔の初期値にし、睡眠や制作は行動固有の区切りを優先する。緊急の世話や設備の使用不能などは中断理由になる。数秒ごとに行動を切り替えて右往左往することを防ぐ。

## 責任と実行条件

勤務や約束は、行動候補を作る前に確認する。欠勤や約束の変更は選択できるが、相手への連絡、代わりを頼む行動、収入や信頼への影響を伴う。

幼い子どもの見守りなど、担当者が必要な責任を手放すには、代わりの担当者が引き受けていることを条件にする。負担の大きい人に交流を提案するときは、休む、支援を頼む、別の日にする選択肢も出す。

準備、移動、待ち時間も本人の時間を消費する。町外の職場や学校にいる間も、勤務、疲労、収入、帰宅時刻を進める。キャラクターが画面に映っていないことを、自由時間として扱わない。[R01、R03、R04]

## プレイヤーの提案

提案は基礎得点に最大0.06を加える。ただし、実行条件、他者の同意、担当が必要な責任を越えられない。受諾、保留、辞退、別案のどれかを返す。

同じ提案、対象、日時、主要な条件が一致する間は、辞退後の再提示で加点しない。勤務の変更、支援の確保、日時の変更などで条件が変われば、再検討できる。

提案した直後に、その場で分かる事情を返す。「その時間は仕事」「二人なら会いたい」「今は作品を進めたい」などと示す。先の成功や隠れた本心をすべて予告せず、判断に関わった事情を読めるようにする。

本人が納得して取り組めること、少しずつ上達できること、誰かとの関わりを感じられることを、別々の経験として記録する。提案への従順さを、自律性や幸福の値に置き換えない。[R05]

## 習慣

習慣は「朝食のあとに水やり」「閉店後に常連と話す」のように、手掛かりと行動を組で保存する。時刻だけでなく、場所や直前の行動も手掛かりになる。[R08]

繰り返しによる強まりは上限に近づくほど小さくする。仮式は H_next = H + 0.04 × (1 - H)。一回休んだだけで0に戻さず、長く実行しない場合の減衰を別に設定する。

この増分は代表日の圧縮に合わせたゲーム用の値であり、現実の習慣ができる日数を示さない。仕事の変更や引っ越しで手掛かりが変わったときは、新しい環境に慣れる過程を作る。

## 人間関係と会話

関係は方向を持つ。AがBに親しみを感じていても、Bの受け止めは別に計算する。家族、同僚、友人などの立場も複数持てる。

同じ場所にいた時間と、実際に関わった時間を分けて記録する。通勤で隣にいたこと、共同作業をしたこと、近況を話したことを区別する。交流の内容と各人の受け止めによって、関係の更新先を変える。[R09]

相手の話を聞く、気持ちを受け止める、自分のことを少し話す、といった応答を扱う。打ち明け話が常に歓迎されるわけではなく、関係、場所、余裕、話題の深さを確認する。[R10]

約束を守れば信頼の更新候補になる。約束が変わった場合は、事情、事前連絡、代案、その後の履行を記録する。会えない期間の長さだけで、すべての関係を同じ速さで失わせない。これらの信頼や修復の数値化はゲーム用の設計。

仕事や活動の情報は、誰から知ったかを保持して伝わる。よく会う知人や別の集まりにいる人が、新しい機会を持ってくることもある。その情報への接触、応募、相手側の判断は別の段階とする。[R12、R13]

会話文は成立した出来事と本人の受け止めを表示する。台詞だけから結婚、退職、物の受け渡しなどの事実を新たに成立させない。

## 公の場と私生活

同じ人物でも、仕事中、家庭、友人との集まり、一人の時間で行動の出やすさを変える。[R07]

役割ごとに話せる話題、守りたい距離、引き受ける責任、慣れた行動を持たせる。店では明るく接客する人が、帰宅後は静かに本を読むこともある。私生活を説明するために、仕事中の振る舞いを嘘として扱う必要はない。

うわさは本人が体験した事実と区別し、発信者と伝聞であることを記録する。住人は自分が知っている範囲で判断する。プレイヤーが別の家で見た出来事を、町の全員に自動共有しない。

## 人生の節目と記憶

転居や卒業が決まるなど、本人が時間の区切りを知ったときは、今会いたい人や取り組みたいことを再検討する。変化の方向と強さは本人の価値観や状況に依存する。高齢であることだけを理由に、新しい出会いや学習を候補から外さない。[R11]

記憶には出来事の事実と本人の解釈を分けて持たせる。二人で過ごした時間でも、一方には楽しい再会、他方には疲れた帰り道として残りうる。

細かな日常は時期ごとにまとめ、約束、作品、共同体験などの重要な記憶を個別に残す。目標の変更時にはそのきっかけとなった経験を参照する。永続的な性格傾向を一回の出来事だけで大きく書き換えない。

## 3D動作との接続

行動は提案への応答、場所の予約、移動、相手との合流、実行、終了または中断の順で進める。双方の参加と場所の確保が成立してから共同体験の記録を始める。

| 行動 | 必要な物や場所 | 主な動き |
|---|---|---|
| 挨拶する | 相手が反応できる位置 | 顔を向ける、手を上げる |
| 話す | 人数分の立ち位置や座席 | 相づち、身振り、相手を見る |
| 一緒に静かに過ごす | 近くの席とそれぞれの道具 | 読む、作業する、ときどき相手を見る |
| 共同作業をする | 作業台と参加人数分の位置 | 道具を使う、見せる、受け渡す |
| 食事する | 座席、食事、テーブル | 座る、食べる、合間に話す |
| 休む | 利用できる椅子や寝床 | 腰を下ろす、横になる、起きる |

物には利用可能な行動、人数、進入位置、手や視線の目標、予約状態を持たせる。子どもと大人の体格差を考慮して、座席と作業位置を合わせる。

移動、上半身の動き、顔と視線を分けて制御する。歩きながら挨拶し、作業の手を止めて振り向けるようにする。動作が中断された場合は、成立済みの効果と消費時間だけを記録し、予約を解放する。

高い倍速では短い身振りを省略できるが、未到着の相手との会話や、存在しない座席での共同体験を成立させない。

## 自律行動と登場人物の拡張計画

2026年11月3日追加。以下はv0.6以降の設計であり、現行実装への接続は今後行う。前述の採点式を設計の基礎に、行動の組合せ、本人の知識、経験による更新を加える。[開発計画](development-roadmap.md)の個性・相互作用・増員の各段階で検証する。

### 行動を組み合わせる

行動定義は人物IDの組合せから独立させ、参加する役割と実行条件を持つ。

| 項目 | 定義する内容 |
|---|---|
| 目的と役割 | 何をしたいか、提案者・協力者・教える人・学ぶ人などの役割 |
| 条件 | 本人が知ること、関心、必要技能、道具、場所、人数、費用、時間 |
| 相談と同意 | 誰に何を依頼するか、受諾・保留・辞退・別案で次にどうするか |
| 実行 | 予約、準備、移動、合流、作業、終了・中断、対応する動作 |
| 結果 | 成立した世界の変化、各人の経験、技能、期待、関係の更新候補 |

住人は本人の目標から短い行動のまとまりを作る。例えば「直したい物がある→直せる人を知る→相談する→時間を合わせる→教わる」の順に進み、相手の返答や道具の空きで見直す。相手は関心、技能、既知関係、場所から探す。既存の葵と修の場面は一つの検証例とし、新しい人物でも同じ定義を使えるようにする。

目的が保たれている間は計画を継続し、実行不能になれば待つ、代案を探す、諦めるなどを選ぶ。手順の上限と再考の区切りを設け、無限に依頼や経路探索を繰り返さない。世界の状態と予約の最終判定は実行側が行う。

### 本人が知ることと受け止め

世界で実際に起きた事実と、住人それぞれが知る情報を分ける。観察や会話で得た情報には、対象、内容、情報源、知った時刻、直接見たか伝聞か、本人の確かさを持たせる。確かさはゲーム用の値であり、現実の人の信念を推定するものではない。

選択時に参照できるのは本人の情報と記憶だけにする。紹介や会話で伝える内容も、話し手が知る範囲から選ぶ。誤解や伝聞があっても世界の事実は書き換えず、後の観察や応答で本人の認識を更新する。記憶を要約するときも、元の出来事と情報源への参照を残す。[R14]

### 経験から次の選び方が変わる

活動の完了や中断で、本人が期待したことと実際に経験したことを比較する。相手、場所、活動、状況に応じた楽しさ、負担、安心、上達の見込みを緩やかに更新する。技能と、本人の「できそう」という見込みも区別する。

例えば、人前で教えることに負担を感じる人でも、親しい一人に教えてうまくいけば、その条件での次の誘いを考えやすくなる。大勢を前に教える見込みや性格全体まで一度に変えない。休めなかった交流も相手を嫌うことだけへ変換せず、その日の疲れや予定を区別する。[R07、R10を参考にしたゲーム用の仮説]

重要な経験と日ごとの振り返りから、願い、試したい行動、習慣の候補を更新する。更新の理由となった出来事を記録し、固定の次の願いだけに依存しない。学習の強さ、忘れ方、更新間隔はゲーム内で調整し、過去の期待が新しい経験を永久に妨げないように確かめる。

### 住人同士が機会を作る

プレイヤーの提案に加え、住人発の紹介、依頼、教え合い、支援の相談、集まりの提案を扱う。紹介された人、頼まれた人にも独立した判断を残す。最初は二者の合意を確実に扱い、その後に主催者と複数参加者の予定・役割・場所を調整する構成へ広げる。

情報を知る、興味を持つ、参加を決める、合流する、継続する段階を分ける。誰かが得た自由時間や技能が別の人の活動を可能にするようにし、協力が続く場合と、負担や行き違いから離れる場合を扱う。関係網の変化と、きっかけになった出来事を対応づける。[R12、R13、R14]

### 増員と生成AIの接続

住人、世帯、仕事、関心、技能、人生の条件、肖像・モデルをデータから参照できる構成へ移す。新しい人の参加、成長、転居を、保存された固有IDと関係の整合性を保って扱う。行動候補の探索は既知関係、必要技能、近隣の場所から絞り、人数増加による判断・関係更新・描画の負荷を別々に測る。

生成AIを使う場合は比較実験として導入し、許可した行動のID、対象、目的、根拠にした本人の記憶、予定の候補を返させる。実行側が条件を検査し、不成立なら既存の候補選択へ戻す。台詞、要約、計画候補に含まれる推測を、未発生の事実や成立済みの合意として保存しない。[R14、R15からの設計判断]

モデルの版、入力、応答、採否を記録し、再現検証では保存した応答を再生する。ゲーム内の学習・判断状態と乱数状態も保存する。オンライン生成がなくても日常が続く方式を先に成立させる。

## 検証する場面

以下は実装後の検証計画であり、現在の動作確認結果ではない。

| 場面 | 確かめること |
|---|---|
| 同じ性格の二人で、片方だけ疲れている | 誘いへの応答が違い、その事情が分かる |
| 同じ人物が店と自宅で過ごす | 性格を入れ替えずに、役割による行動差が出る |
| 家事の分担と勤務時刻を入れ替える | 性別の変更に頼らず、会える条件が変わる |
| 二人が同じ部屋で別々のことをする | 会話し続けなくても、本人に合う時間になる |
| 提案を断られ、空いている日時に変更する | 連打では加点されず、条件の変更で再検討される |
| 習慣を一回休み、その後再開する | 全消去されず、元の手掛かりに応じて再開できる |
| 若い人の転居が決まる。高齢者には予定の区切りがない | 年齢だけでなく、知っている時間の区切りが影響する |
| 座席が足りない。相手が移動を中断する | 共同体験が架空に記録されない |
| 同じ保存状態から通常速度と倍速で進める | 表示の省略が、判断と交流の処理順を変えない |
| 町外勤務と睡眠が日をまたぐ | 責任や拘束時間が午前0時で消えない |
| 同じ性格と予定で、過去の共同作業の経験だけを変える | 状況に応じた期待と次の選択が変わり、理由を記録から追える |
| 一人だけが設備の空きや活動の情報を知っている | 会話や観察を経て情報が伝わり、未知の情報を使わない |
| 同じ行動へ別の住人を参加させる | 固定の人物ペアへの分岐を追加せず、技能・関心・合意から進む |
| 知人が協力者を紹介し、教わった人が第三者を手伝う | 自律した行動が複数人を介してつながり、各段階に実際の経験がある |
| 人数を8人から16人、次に24人へ増やす | 日常と交流の供給、人物を追う操作、性能、保存の条件を満たす |
| 同じ初期状態・seed・入力・外部応答を再生する | 学習を含む選択と結果を再現できる |
| seed、住人構成、初期関係、設備をそれぞれ変える | 台詞の違いに加え、相手・協力・習慣・作品の違いが生まれる |

8人の試作は架空の小集団として評価する。全国の平均値に8人全員を近づけない。統計との比較は、実装後に条件別の多数の生活履歴を生成し、平日・休日、就業状態、世帯内の責任、対象年齢をそろえて行う。
