# Haru authoring inputs

`CH_Haru_FingerIsolation_Master.blend` is the current authoring master referenced by the runtime asset manifest. `CH_Haru_LegacyDelivery.blend` is the distinct older delivery input still used by the smile and LOD staging scripts. Neither is a disposable verification render or interchangeable with the other.

These files were moved from generated builds directories during handoff cleanup. The raw Tripo mesh remains in `../raw/`, and export input fixtures live in `../production-inputs/`. This relocation does not establish new deformation, visual or gameplay acceptance.
