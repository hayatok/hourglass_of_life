# r3 LOD seam correction

The original decimation operated on disconnected UV/normal seam vertices. In the r2 files, analysis that joins equal-position endpoints at 1 micrometre finds 1,458 unmatched head/neck boundary edges in LOD1 (21.03 m combined), and 1,197 in LOD2 (30.65 m). Coincident vertices have identical skin weights, so a weight mismatch alone does not explain the defects. Large rest-geometry gaps are already present before the head turns.

r3 welds coincident vertices before reduction while keeping UV coordinates on face loops. The retained UV-loop coordinate multiset is unchanged by the weld. Merge cleanup removes 18 small faces and 54 UV loops; these are not claimed to be strictly zero-area faces. The removed source-face areas in the diagnostic range up to approximately 0.518 square millimetres. No original image, LOD0 geometry, source rig, stride or animation track changes are included.

The resulting LOD1/2 have 12,190 / 3,482 triangles. Both retain exactly the LOD0 inverse-bind matrices and names/order, and exactly the same nine animation tracks and samples. Skin weights are normalized with four influences maximum. Their material slots remain geometry-only with zero embedded images, retaining r2's texture-memory policy. The actor retains its current TextureEyes material and source atlas across LOD swaps.

Native GPU comparison uses the current eye adapter, rest pose, idle at 0.6 seconds and a real manual 0.6-radian head yaw. Animation callbacks are manual during these snapshots so the requested head turn is not overwritten by playback. Forced close views and approximate normal views at 95 / 40 actual subject pixels are retained. Each r2/r3 GPU run passes 17 structural checks. Agent visual review and the root agent's independent visual review confirm that the large facial, neck and hair cracks disappear in r3. These are automated/agent checks, not human playtesting.

The corrected meshes still have 20 unmatched geometric boundary edges with total length 30.89 mm, including six head/neck edges totaling 8.57 mm. No fully watertight claim is made. An attempted bounded hole-fill found no closed boundary loops and added zero faces; it did not change this residual. The large gap problem is improved visibly, while this small topological residue remains recorded for later inspection.

Production r3 changes only the two distance GLBs and the related manifest keys. LOD0 remains SHA-256 `1fe9857d04300aee6de13d905f34a8ec86630bc0b86008f1095a908faf47b7cf`. The previous r2 production assets are archived under `builds/haru-cute-pilot/r2-production-snapshot/`. Face shader work, Smile, hair aging and the inherited gait's stance sliding remain separate acceptance work.
